    Function useDebouncedDrag

    • useDebouncedDrag(options?: DebouncedDragOptions): DebouncedDragResult

      Хук для оптимизации drag операций с debouncing

      Предотвращает отправку множества обновлений при быстрых движениях мыши. Вместо отправки 60+ событий в секунду, отправляется максимум 60 (при 16ms delay).

      Parameters

      • options: DebouncedDragOptions = {}

      Returns DebouncedDragResult

      Example

      const { debouncedDragUpdate, immediateDragUpdate } = useDebouncedDrag({
        delay: 16, // 60fps
        onDragUpdate: (x) => setLocalPosition(x), // Мгновенное обновление UI
        onDragCommit: (x) => updateSlip(x), // Debounced обновление state
      })

      // В mousemove handler
      const handleMouseMove = (e: MouseEvent) => {
        debouncedDragUpdate(e.clientX)
      }
