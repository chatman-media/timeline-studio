      • Хук для доступа к Browser Resources Provider контексту

        Returns EffectsProviderContext

        Контекст провайдера с ресурсами и API

        Description

        Предоставляет доступ к библиотеке ДОСТУПНЫХ ресурсов для Browser компонента. Этот хук используется для получения эффектов, фильтров, переходов и медиа файлов, доступных для выбора пользователем.

        Throws

        Если хук используется вне BrowserResourcesProvider

        Example

        function BrowserTab() {
          const { getResources, isLoading } = useBrowserResourcesProvider()
          const effects = getResources('effect')

          if (isLoading) return <Spinner />

          return (
            <div>
              {effects.map(effect => (
                <EffectCard key={effect.id} effect={effect} />
              ))}
            </div>
          )
        }
