# Timeline Studio 3.14.0 - Приоритет локальных AI-моделей

Timeline Studio 3.14.0 делает важный шаг в сторону приватности и независимости - локальные AI-модели теперь автоматически выбираются первыми при использовании AI-функций.

## 🔐 Главная возможность

### 🏠 Приоритет локальных моделей

Ваши данные остаются на вашем компьютере:

- **Автоматический выбор** локальных моделей (Ollama, LM Studio)
- **Полная приватность** - данные не покидают ваш компьютер
- **Работа оффлайн** - не нужен интернет для AI-функций
- **Экономия на API** - бесплатное использование локальных моделей

Теперь при открытии AI Chat приложение сначала проверяет доступность локальных моделей:

1. **Ollama** - если установлен и работает
2. **LM Studio** - если доступен локально
3. **Облачные модели** - только если локальные недоступны

### 🛡️ Поддержка MCP Claude

Добавлена поддержка Model Context Protocol для Claude:

- **MCP-совместимость** с Claude Desktop
- **Безопасный импорт** API ключей с типом mcp_claude
- **Интеграция с локальными сервисами** через MCP

## 🐛 Исправления

- **Улучшена интеграция с AI** - исправлены проблемы с выбором моделей
- **Обновлены тесты** для новой логики выбора моделей
- **Исправлены проблемы безопасности** при импорте API ключей

## 💡 Почему это важно

### Приватность
Ваши видеопроекты, диалоги с AI и все промежуточные данные остаются локально. Никто не получает доступ к вашему контенту.

### Независимость
Не зависите от доступности облачных сервисов или интернет-соединения. Работайте где угодно.

### Экономия
Локальные модели бесплатны в использовании. Никаких счетов за API, никаких лимитов.

### Производительность
Для многих задач локальные модели работают быстрее - нет задержек на передачу данных в облако.

## 🚀 Как настроить

### Установка Ollama

1. Скачайте [Ollama](https://ollama.ai)
2. Установите рекомендуемые модели:
   ```bash
   ollama pull llama2
   ollama pull codellama
   ollama pull mistral
   ```
3. Запустите Ollama - Timeline Studio автоматически обнаружит его

### Использование

1. Откройте AI Chat в Timeline Studio
2. Приложение автоматически выберет локальную модель
3. Начинайте работать - всё локально!
