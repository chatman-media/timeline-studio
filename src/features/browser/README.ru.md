# Browser

[English](./README.md) | **Русский**

## Обзор

Модуль Browser предоставляет табличный интерфейс для просмотра и управления различными типами медиа файлов и ресурсов в Timeline Studio. Служит основной точкой входа для импорта и организации ресурсов проекта.

## Статус

**🎉 100% Готов** - Весь основной функционал полностью реализован и протестирован.

- ✅ **Компоненты**: Полная система вкладок с Media, Music, Transitions, Effects, Subtitles, Filters, Templates, Style Templates (8 активных вкладок)
- ✅ **Хуки**: Импорт музыки, управление ресурсами, поиск, фильтрация, избранное
- ✅ **Сервисы**: Стейт-машина браузера (XState), загрузчики ресурсов с ленивой загрузкой
- ✅ **Тесты**: 535 тестов пройдено (534 + 1 пропущен), 71.73% покрытие

## Использование

```typescript
import { Browser } from '@/features/browser'

function MediaStudio() {
  return (
    <div>
      <Browser />
    </div>
  )
}
```

### Использование хука состояния браузера

```typescript
import { useBrowserState } from '@/features/browser'

function MyComponent() {
  const { activeTab, switchTab, selectedFiles } = useBrowserState()

  return (
    <div>
      <button onClick={() => switchTab('media')}>
        Переключиться на Media
      </button>
    </div>
  )
}
```

### Хук импорта музыки

```typescript
import { useMusicImport } from '@/features/browser'

function MusicTab() {
  const { importFile, importDirectory, isImporting, progress } = useMusicImport()

  return (
    <div>
      <button onClick={importFile}>Импорт файла</button>
      <button onClick={importDirectory}>Импорт папки</button>
      {isImporting && <progress value={progress} max={100} />}
    </div>
  )
}
```
