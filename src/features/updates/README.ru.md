# Updates

[English](./README.md) | **Русский**

## Обзор

Модуль обновлений обеспечивает комплексное управление обновлениями приложения Timeline Studio, включая автоматические обновления, уведомления и пользовательские настройки через систему обновлений Tauri.

## Статус

- ✅ **Компоненты**: 4 компонента для UI обновлений (менеджер, уведомления, настройки, индикатор)
- ✅ **Хуки**: 1 хук для управления обновлениями
- ✅ **Сервисы**: XState машина и сервис обновлений с интеграцией Tauri
- ✅ **Тесты**: Доступны тесты компонентов и сервисов

## Структура

```
updates/
├── components/                      # UI компоненты
```

## Возможности

### ✅ Реализовано

**Управление обновлениями:**
- [x] Автоматическая проверка обновлений (периодические фоновые проверки)
- [x] Ручная проверка обновлений (инициированная пользователем)
- [x] Управление загрузкой с отслеживанием прогресса
- [x] Контроль установки с подтверждением пользователя

**Пользовательский опыт:**
- [x] Уведомления об обновлениях (ненавязчивые)
- [x] Индикаторы прогресса (в реальном времени)
- [x] Управление настройками (пользовательские предпочтения)
- [x] Визуализация статуса (четкое указание состояния)

**Состояния обновления:**
- [x] `idle` - Нет активности обновления
- [x] `checking` - Проверка обновлений
- [x] `available` - Обновление готово к загрузке
- [x] `downloading` - Обновление загружается
- [x] `downloaded` - Обновление готово к установке
- [x] `installing` - Обновление устанавливается
- [x] `error` - Произошла ошибка

### ❌ Не реализовано

**Продвинутые возможности:**
- [ ] Дифференциальные обновления (только измененные файлы)
- [ ] Возможность отката (возврат к предыдущим версиям)
- [ ] Планирование обновлений (в определенное время)
- [ ] Ограничение скорости загрузки
- [ ] Фоновые обновления (тихие обновления)
- [ ] Каналы обновлений (переключение stable/beta/alpha)

## Использование

```typescript
import { useUpdateManager } from '@/features/updates';

function App() {
  const {
    state,
    checkForUpdates,
    downloadUpdate,
    installUpdate,
    dismissUpdate
  } = useUpdateManager();

  return (
    <div>
      <button onClick={checkForUpdates}>
        Проверить обновления
      </button>

      {state === 'available' && (
        <button onClick={downloadUpdate}>
          Скачать обновление
        </button>
      )}

      {state === 'downloaded' && (
        <button onClick={installUpdate}>
          Установить и перезапустить
        </button>
      )}
    </div>
  );
}
```

## Интеграция

- **Зависит от**: `@tauri-apps/api` (система обновлений Tauri)
- **Используется в**: `@/features/app-settings`, Главный UI приложения
- **Backend команда**: `download_and_install_update` (команда Tauri)

## Конфигурация

### Конфигурация Tauri

```json
{
  "updater": {
    "active": true,
    "endpoints": ["https://releases.timeline-studio.com/updates"],
    "dialog": false,
    "pubkey": "ваш-публичный-ключ-здесь"
  }
}
```

### Настройки обновлений

- **Автопроверка**: Включить/отключить автоматическую проверку
- **Интервал проверки**: Каждый час, день, неделю
- **Автозагрузка**: Автоматически загружать обновления
- **Автоустановка**: Автоматически устанавливать обновления
- **Настройки уведомлений**: Контроль отображения уведомлений

## Функции безопасности

- **Проверка подписи**: Все обновления криптографически подписаны
- **Проверка контрольной суммы**: Файлы проверяются перед установкой
- **Защищенные каналы**: Только HTTPS для коммуникации
- **Согласие пользователя**: Явное подтверждение для установок
