# Modals

[English](./README.md) | **Русский**

## Обзор

Централизованная система управления модальными окнами для Timeline Studio с использованием XState машины состояний для унифицированного контроля диалогов в приложении.

## Статус

- ✅ **Компоненты**: ModalContainer с плавными переходами
- ✅ **Машина состояний**: Управление жизненным циклом на основе XState
- ✅ **Провайдер**: React Context для глобального доступа
- ✅ **Тесты**: 4 тестовых файла (провайдер, машина, контейнер, интеграция)

## Структура

```
modals/
├── components/
│   ├── modal-container.tsx       # Основной рендерер модальных окон
│   └── [20+ модальных окон]      # Конкретные реализации
├── hooks/
│   └── use-modal.ts              # Хук управления модальными окнами
├── services/
│   ├── modal-machine.ts          # XState машина состояний
│   └── modal-provider.tsx        # React Context провайдер
├── types/
│   └── modal.ts                  # TypeScript определения
└── __tests__/                    # Тестовые файлы
```

## Возможности

### ✅ Реализовано

- [x] Одно активное окно с отслеживанием истории
- [x] Поддержка навигации с возвратом
- [x] Типобезопасное управление данными
- [x] Настраиваемые размеры через Tailwind классы

- [x] Плавные переходы между окнами

**Медиа и запись**: camera-capture, voice-recording, audio-effects
**Управление проектом**: export, project-settings, missing-files
**Интерфейс**: user-settings, keyboard-shortcuts, effect-detail, color-grading
**Редактирование**: subtitle-editor, subtitle-ai-tools, person-form, ai-marker-settings
**Система**: cache-settings, cache-statistics
**MIDI**: midi-learn, midi-mapping, midi-configuration

## Использование

```typescript
import { useModal } from '@/features/modals'

function MyComponent() {
  const { openModal, closeModal } = useModal()

  // Открыть окно с данными
  const handleExport = () => {
    openModal('export', {
      format: 'mp4',
      quality: 'high'
    })
  }

  // Открыть с возвратом
  const handleSettings = () => {
    openModal('cache-settings', {
      returnTo: 'user-settings'
    })
  }

  // Настройка размера
  openModal('modal-type', {
    dialogClass: 'max-w-4xl'
  })
}
```
