# Camera Capture

[English](./README.md) | **Русский**

## Обзор

Модуль Camera Capture предоставляет функциональность записи видео с камеры и экрана с выбором устройств, настройками качества и превью в реальном времени. Использует Web API для захвата медиа без зависимостей от backend.

## Статус

- ✅ **Компоненты**: Полный UI с модальным окном, превью, настройками и элементами управления
- ✅ **Хуки**: Управление потоком камеры, устройствами, записью, захватом экрана
- ✅ **Сервисы**: Основано на Web API (MediaDevices, MediaRecorder, Screen Capture API)
- ✅ **Тесты**: 68 тестов пройдено, 95.39% покрытие компонентов, 72.9% покрытие хуков

## Использование

### Основной компонент

```typescript
import { CameraCaptureModal } from '@/features/camera-capture'

function App() {
  const [isOpen, setIsOpen] = useState(false)

  return (
    <CameraCaptureModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
    />
  )
}
```

### Хуки

#### useDevices - Управление устройствами

```typescript
const {
  videoDevices,      // Список камер
  audioDevices,      // Список микрофонов
  selectedVideoId,   // ID выбранной камеры
  selectedAudioId,   // ID выбранного микрофона
  setSelectedVideoId,
  setSelectedAudioId,
  refreshDevices     // Обновить список устройств
} = useDevices()
```

#### useCameraStream - Управление видеопотоком

```typescript
const {
  stream,           // MediaStream
  isLoading,        // Загрузка потока
  error,            // Ошибка
  startStream,      // Запустить поток
  stopStream        // Остановить поток
} = useCameraStream({
  videoDeviceId,
  audioDeviceId,
  constraints       // MediaStreamConstraints
})
```

#### useRecording - Запись видео

```typescript
const {
  isRecording,      // Идет запись
  isPaused,         // Пауза
  recordingTime,    // Время записи в секундах
  startRecording,   // Начать запись
  stopRecording,    // Остановить и получить Blob
  pauseRecording,   // Пауза
  resumeRecording   // Продолжить
} = useRecording(mediaStream)
```

#### useScreenCapture - Запись экрана

```typescript
const {
  screenStream,       // MediaStream экрана
  isScreenSharing,    // Идет запись экрана
  error,              // Ошибка
  startScreenCapture, // Начать запись экрана
  stopScreenCapture,  // Остановить запись
  getSourceInfo       // Получить информацию об источнике
} = useScreenCapture()
```

## Технические примечания

- Формат записи: WebM (VP8/VP9)
- Требуются современные браузеры с MediaRecorder API
- Для доступа к камере требуется HTTPS или localhost
- Разрешения запрашиваются при первом использовании
- Разрешения macOS настроены в `src-tauri/Info.plist`
- CSP политика включает `mediastream:` для Web APIs
