# Options - Панель настроек

[English](./README.md) | **Русский**

## Обзор
Унифицированная панель настроек с полным контролем над цветокоррекцией, скоростью воспроизведения, аудио настройками и информацией о медиа.

## Статус
- ✅ **Компоненты**: Все ключевые компоненты полностью реализованы
- ✅ **Хуки**: Хуки интеграции с Timeline готовы
- ✅ **Тесты**: 10+ тестов успешно проходят (компоненты, интеграция)

## Структура
```
options/
├── components/
│   ├── options.tsx              # Главный интерфейс с вкладками
│   ├── audio-settings.tsx       # Профессиональные аудио настройки
│   ├── speed-settings.tsx       # Управление скоростью и таймингом
│   └── info-settings.tsx        # Отображение информации о медиа
└── __tests__/
    └── components/              # Тесты компонентов
```

## Использование
```typescript
import { Options } from '@/features/options'

// Базовое использование
<Options selectedMediaFile={currentMediaFile} />

// Интеграция с Timeline (автоматическая)
const { selectedClipIds, clips } = useTimeline()
// Компонент Options автоматически обрабатывает состояние Timeline
```

## Интеграция
- **Зависимости**: @/features/timeline, @/features/color-grading
- **Используется в**: @/features/media-studio
- **Timeline**: Безопасная интеграция с автоматическим обнаружением клипов
