# Resources

[English](./README.md) | **Русский**

## Обзор

Система управления ресурсами для Timeline Studio. Управляет эффектами, фильтрами, переходами, шаблонами, музыкой и субтитрами. Обеспечивает централизованное управление состоянием, отслеживание ресурсов и интеграцию с компонентами таймлайна и браузера.

## Статус

- ✅ **Компоненты**: ResourcesPanel (511 тестов)
- ✅ **State Machine**: XState машина ресурсов
- ✅ **Провайдер**: React Context провайдер
- ✅ **Тесты**: 511 тестов проходят
- ⚠️ **Интеграция**: Частичная - только Timeline и Browser

## Использование

```typescript
import { useResources } from '@/features/resources'

function ResourceManager() {
  const { resources, addResource, removeResource } = useResources()

  return (
    <div>
      {Object.entries(resources).map(([category, items]) => (
        <div key={category}>
          <h3>{category}</h3>
          <p>Количество: {items.length}</p>
          {items.map(resource => (
            <div key={resource.id}>
              <span>{resource.name}</span>
              <button onClick={() => removeResource(category, resource.id)}>
                Удалить
              </button>
            </div>
          ))}
        </div>
      ))}
    </div>
  )
}
```

## Интеграция

- **Зависит от**:
  - `xstate` - для state machine
  - `react-i18next` - для интернационализации
  - `lucide-react` - для иконок
  - `@/features/effects` - для типов эффектов
  - `@/features/filters` - для типов фильтров
  - `@/features/transitions` - для типов переходов
  - `@/features/templates` - для типов шаблонов
  - `@/features/style-templates` - для стилевых шаблонов
- **Используется в**:
  - `@/features/timeline` - для отображения ресурсов
  - `@/features/browser` - для управления ресурсами
  - `@/features/media-studio` - для интеграции в редактор
