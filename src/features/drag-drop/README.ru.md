# Drag & Drop

[English](./README.md) | **Русский**

## Обзор

Глобальная система управления drag-and-drop для Timeline Studio. Предоставляет единообразную функциональность перетаскивания для всех модулей (медиа файлы, эффекты, фильтры, переходы, шаблоны). Использует паттерн singleton для координации операций между различными частями приложения.

## Статус

- ✅ **Компоненты**: N/A (система на основе хуков)
- ✅ **Хуки**: useDraggable, useDropZone, useDragDropState
- ✅ **Сервисы**: DragDropManager singleton с EventEmitter
- ✅ **Тесты**: Полное покрытие (хуки и менеджер), 4 SSR теста пропущены

## Использование

### Сделать элемент перетаскиваемым

```typescript
import { useDraggable } from '@/features/drag-drop'

function MediaFileItem({ file }) {
  const { dragHandlers } = useDraggable({
    type: 'media',
    getData: () => file,
    getPreview: () => ({
      url: file.thumbnail,
      width: 100,
      height: 100
    })
  })

  return (
    <div {...dragHandlers}>
      <img src={file.thumbnail} />
      <span>{file.name}</span>
    </div>
  )
}
```

### Создание зоны сброса

```typescript
import { useDropZone } from '@/features/drag-drop'

function TimelineDropZone() {
  const dropZoneRef = useRef<HTMLDivElement>(null)

  useDropZone({
    id: 'timeline-drop',
    accepts: ['media', 'effect', 'filter', 'transition'],
    elementRef: dropZoneRef,
    onDrop: (item, event) => {
      if (item.type === 'media') {
        addMediaToTimeline(item.data, event.clientX)
      }
    },
    onDragEnter: (item) => {
      // Показать индикатор сброса
    },
    onDragLeave: () => {
      // Скрыть индикатор сброса
    }
  })

  return <div ref={dropZoneRef} className="timeline-drop-zone" />
}
```

### Доступ к состоянию перетаскивания

```typescript
import { useDragDropState } from '@/features/drag-drop'

function DragStateIndicator() {
  const { isDragging, currentItem } = useDragDropState()

  if (!isDragging) return null

  return (
    <div className="drag-indicator">
      Перетаскивание: {currentItem?.type}
    </div>
  )
}
```

### Прямое использование менеджера (расширенное)

```typescript
import { getDragDropManager } from '@/features/drag-drop'

const manager = getDragDropManager()

// Слушать события перетаскивания
manager.on('dragStart', (state) => {
  console.log('Перетаскивание началось:', state)
})

manager.on('dragEnd', () => {
  console.log('Перетаскивание завершено')
})
```

## Архитектура

### Паттерн Singleton
`DragDropManager` использует паттерн singleton для обеспечения единственного экземпляра, управляющего всеми операциями перетаскивания.

### Жизненный цикл событий

1. **dragStart** - Пользователь инициирует перетаскивание
2. **dragOver** - Мышь движется над зоной сброса
3. **dragEnter** - Мышь входит в зону сброса
4. **dragLeave** - Мышь покидает зону сброса
5. **drop** - Пользователь отпускает мышь
6. **dragEnd** - Операция перетаскивания завершается

### Система Ghost изображений
Пользовательское превью перетаскивания создается из данных превью с позиционированием через стили.

## Обратная совместимость

Менеджер поддерживает как новую единую систему, так и legacy dataTransfer типы:

```typescript
// Новый единый способ (рекомендуется)
event.dataTransfer.setData('application/json', JSON.stringify(item))

// Legacy совместимость (для старого кода)
switch (item.type) {
  case 'media':
    event.dataTransfer.setData('mediaFile', JSON.stringify(item.data))
    break
  // ... другие типы
}
```

## Производительность

- **Паттерн Singleton** - Единственный экземпляр менеджера, минимальные затраты памяти
- **Делегирование событий** - Глобальные слушатели вместо слушателей на каждом элементе
- **Ленивое создание ghost** - Ghost изображение создается только при наличии превью
- **Эффективный поиск зон** - Реестр зон сброса на основе Map
- **Очистка при unmount** - Хуки автоматически отменяют регистрацию зон
