# Publication

[English](./README.md) | **Русский**

## Обзор

Система управления задачами публикации для Timeline Studio. Обеспечивает интеграцию с видеохостингами (YouTube, TikTok, VK) через систему плагинов. Отслеживает прогресс загрузки, управляет метаданными публикации и отслеживает статус задач.

## Статус

- ✅ **Компоненты**: Выпадающий список задач публикации
- ✅ **Хуки**: use-publication-tasks
- ✅ **Типы**: Типы задач публикации и статусов
- ⚠️ **Тесты**: Ещё не реализованы

## Использование

```typescript
import { usePublicationTasks } from '@/features/publication'

function PublicationPanel() {
  const {
    tasks,           // Массив задач публикации
    isLoading,       // Состояние загрузки
    error,           // Сообщение об ошибке
    refreshTasks,    // Ручное обновление
    getTask,         // Получить задачу по ID
    cancelTask,      // Отменить загрузку
  } = usePublicationTasks()

  if (isLoading) return <div>Загрузка...</div>
  if (error) return <div>Ошибка: {error}</div>

  return (
    <div>
      {tasks.map(task => (
        <div key={task.id}>
          <h3>{task.title}</h3>
          <p>Статус: {task.status}</p>
          {task.progress && (
            <progress value={task.progress.percentage} max={100} />
          )}
          <button onClick={() => cancelTask(task.id)}>Отменить</button>
        </div>
      ))}
    </div>
  )
}
```

  - Plugin system: `youtube-uploader` плагин
