# Язык

[English](./README.md) | **Русский**

## Обзор

Модуль управления языком для Timeline Studio. Обеспечивает плавное переключение между 15 поддерживаемыми языками с синхронизацией между фронтендом (i18next) и бэкендом (Tauri). Поддерживает RTL языки (арабский, персидский) и автоматическое определение системного языка.

## Статус

- ✅ **Хуки**: useLanguage (автоопределение, смена, персистентность)
- ✅ **Интеграция**: i18next, Tauri Store, fallback на localStorage
- ✅ **Языки**: 15 языков с нативными названиями и поддержкой RTL
- ❌ **Тесты**: Пока нет unit тестов (запланировано)

## Использование

### Базовое использование хука

```typescript
import { useLanguage } from '@/features/language'

function LanguageSelector() {
  const {
    currentLanguage,    // Текущий язык приложения
    systemLanguage,     // Определенный системный язык
    isLoading,          // Состояние загрузки
    error,              // Состояние ошибки
    changeLanguage,     // Функция смены языка
    refreshLanguage,    // Обновление из бэкенда
  } = useLanguage()

  const handleChange = async (lang: LanguageCode) => {
    await changeLanguage(lang)
  }

  return (
    <select value={currentLanguage} onChange={(e) => handleChange(e.target.value)}>
      <option value="en">English</option>
      <option value="ru">Русский</option>
      {/* ... другие языки */}
    </select>
  )
}
```

### Автоматическое определение языка

Хук автоматически:
1. Получает язык из Tauri бэкенда при монтировании
2. Определяет системный язык
3. Применяет сохраненные языковые предпочтения
4. Использует fallback на localStorage если Tauri недоступен
5. По умолчанию использует английский если настройки не найдены

### Персистентность языка

Язык сохраняется на нескольких уровнях:
- **Tauri Store** (основной) - Кроссплатформенное персистентное хранилище
- **localStorage** (fallback) - Хранилище браузера
- **i18next** (runtime) - Активное состояние переводов

## Интеграция

- **Зависит от**:
  - `@/i18n` - Константы переводов и конфигурация i18next
  - `@tauri-apps/api/core` - Команды бэкенда (`get_app_language_tauri`, `set_app_language_tauri`)
  - `react-i18next` - Runtime переводов

- **Используется в**:
  - Модальном окне User Settings - UI выбора языка
  - Инициализации приложения - Автоматическое определение языка
  - Всех переведенных компонентах - через i18next

## Tauri команды

Модуль использует две Tauri команды:

| Команда | Параметры | Ответ | Описание |
|---------|-----------|-------|----------|
| `get_app_language_tauri` | - | `{ language: string, system_language: string }` | Возвращает текущий язык приложения и системный язык |
| `set_app_language_tauri` | `{ lang: string }` | `{ language: string, system_language: string }` | Устанавливает язык приложения и сохраняет в Tauri Store |
