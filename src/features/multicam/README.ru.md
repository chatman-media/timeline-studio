# Multicam

[English](./README.md) | **Русский**

## Обзор

Система мультикамерного монтажа для Timeline Studio, предоставляющая синхронизацию, переключение и редактирование видео с нескольких камер одновременно с поддержкой синхронизации по таймкоду и аудио.

## Статус

**🎉 100% Готово** - Весь основной функционал полностью реализован и протестирован.

- ✅ **Компоненты**: AngleViewer, SyncControls, AudioSyncDialog
- ✅ **Хуки**: useMulticam, useMulticamShortcuts, useVideoLazyLoading
- ✅ **Сервисы**: MulticamManager, синхронизация по таймкоду, синхронизация по аудио
- ✅ **Тесты**: 16 тестовых файлов с комплексным покрытием

## Использование

### Базовая настройка

```typescript
import { useMulticam, AngleViewer } from '@/features/multicam'

function MulticamEditor() {
  const baseClipId = "clip-123"
  const multicam = useMulticam(baseClipId)

  return (
    <div>
      <AngleViewer
        baseClipId={baseClipId}
        onAngleClick={(angle, index) => {
          console.log(`Выбрана камера ${index + 1}`)
        }}
      />

      <div>
        Активная камера: {multicam.activeAngle?.name}
      </div>
    </div>
  )
}
```

### Программное переключение

```typescript
const multicam = useMulticam(baseClipId)

// Переключиться на камеру 2
multicam.switchToAngle(1) // индекс с 0

// Следующая камера
multicam.switchToNextAngle()

// Предыдущая камера
multicam.switchToPreviousAngle()
```

### Синхронизация

```typescript
// Автосинхронизация по таймкоду
multicam.autoSyncByTimecode()

// Автосинхронизация по аудио
await multicam.autoSyncByAudio()

// Ручная настройка смещения
multicam.setSyncOffset(angleIndex, offsetSeconds)

// Применить синхронизацию
multicam.syncAngles()
```

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| 1-9 | Переключение на камеру 1-9 |

Горячие клавиши автоматически активируются при использовании `useMulticam`.

## Методы синхронизации

### Синхронизация по таймкоду
- Извлечение таймкода из метаданных видео (SMPTE)
- Поддержка стандартного (HH:MM:SS:FF) и drop frame (HH:MM:SS;FF)
- Автоматическое выравнивание клипов

### Синхронизация по аудио
- Анализ аудиодорожек для поиска совпадающих сегментов
- Алгоритм корреляции для сопоставления сигналов
- Визуальная обратная связь процесса
- Оценка качества синхронизации

### Ручная синхронизация
- Точная настройка смещения через слайдеры
- Контроль смещения для каждой камеры
