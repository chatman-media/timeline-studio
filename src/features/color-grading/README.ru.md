# Color Grading

[English](./README.md) | **Русский**

## Обзор

Профессиональная система цветокоррекции, интегрированная в панель Options Timeline Studio. Предоставляет возможности цветокоррекции уровня DaVinci Resolve, включая цветовые круги, RGB кривые, HSL настройки, поддержку LUT и профессиональные инструменты анализа.

## Статус

- ✅ **Компоненты**: Полный UI с цветовыми кругами, кривыми, HSL, LUT и анализаторами
- ✅ **Хуки**: Централизованное управление состоянием через useColorGrading хук
- ✅ **Сервисы**: Только фронтенд, CSS фильтры и обработка через canvas
- ✅ **Тесты**: Модульные тесты для хуков и управления состоянием

## Использование

### Интеграция с панелью Options

```typescript
import { ColorSettings } from "@/features/color-grading/components/color-settings"

// В options.tsx
{activeTab === "color" && <ColorSettings />}
```

### Использование хука

```typescript
import { useColorGrading } from "@/features/color-grading/hooks/use-color-grading"

function MyComponent() {
  const {
    state,
    updateColorWheel,
    updateBasicParameter,
    updateCurve,
    loadLUT,
    resetAll,
    hasChanges
  } = useColorGrading()

  // Обновить цветовой круг
  updateColorWheel("lift", { r: 10, g: 20, b: 30 })

  // Обновить температуру
  updateBasicParameter("temperature", 50)

  // Загрузить LUT
  loadLUT("film-kodak-2383")
}
```

### Паттерн Dispatch

```typescript
dispatch({
  type: "UPDATE_CURVE",
  curve: "master",
  points: curvePoints
})

dispatch({
  type: "TOGGLE_SCOPE",
  scopeType: "waveform",
  enabled: true
})
```

- Пакетные обновления состояния через dispatch
- Debounced ввод для слайдеров

## Технические детали

### Цветовые круги
- Интерактивные SVG-основанные круги
- Функциональность drag & drop с визуальной обратной связью
- Обновления значений в реальном времени
- Функция сброса для каждого круга

### Редактор кривых
- Master и RGB канальные кривые
- Интерактивная манипуляция точками
- Интерполяция кривых Bézier для плавных градиентов
- Добавление/удаление точек через клик/двойной клик
- Сетка для точности

### Система LUT
- Импорт .cube файлов через Tauri диалог
- Встроенные LUT пресеты в трех категориях:
  - Эмуляция пленки (Kodak, Fuji и др.)
  - Креативные looks (Orange & Teal, Vintage и др.)
  - Технические (S-Log to Rec.709 и др.)
- Управление интенсивностью (0-100%)
- Триlinear интерполяция для плавного применения

### Профессиональные анализаторы
- **Waveform**: Расчет яркости ITU-R BT.709 с RGB парадом
- **Vectorscope**: Визуализация цветового пространства YUV с линией тона кожи
- **Histogram**: Распределение RGB каналов с прозрачными слоями
- Рендеринг на основе Canvas для производительности
- Настраиваемая частота обновления (15/30/60 FPS)
- Полноэкранный режим просмотра
