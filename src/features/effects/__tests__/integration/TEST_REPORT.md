## Архитектурные компоненты

### Тестируемые сервисы

1. **EffectManager** - центральная система управления эффектами
   - Регистрация и поиск эффектов
   - Применение эффектов к объектам
   - Управление стеками эффектов
   - Создание и применение пресетов
   - Система событий

2. **Базовые эффекты**
   - `colorCorrectionEffect` - профессиональная цветокоррекция
   - `gaussianBlurEffect` - гауссово размытие
   - `vintageEffect` - винтажная стилизация

### Тестируемые типы

- `BaseEffect` - базовая структура эффекта
- `AppliedEffect` - применённый эффект с состоянием
- `EffectParameter` - параметры эффекта
- `EffectKeyframe` - ключевые кадры анимации
- `EffectPreset` - пресеты эффектов
- `EffectStack` - стек эффектов на объекте
