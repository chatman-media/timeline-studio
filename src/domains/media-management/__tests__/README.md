## Основные сценарии тестирования

### 1. Импорт медиа файлов
```typescript

  generateThumbnails: true,
```

## Edge Cases

Тесты покрывают следующие граничные случаи:

1. **Пустые данные:**
   - Пустой список файлов
   - Отсутствующие метаданные
   - Неизвестные типы файлов

2. **Ошибки:**
   - Ошибки файловой системы
   - Ошибки FFmpeg
   - Недоступные файлы
   - Частичные ошибки при пакетном импорте

3. **Специальные символы:**
   - Длинные пути к файлам
   - Кириллица и спецсимволы в именах
   - Пробелы в путях

4. **Производительность:**
   - Конкурентные операции
   - Быстрые последовательные обновления
   - Большое количество операций

## Best Practices

1. **Изоляция тестов:** Каждый тест использует свой экземпляр actor/service
2. **Cleanup:** `beforeEach` сбрасывает все моки
3. **Async handling:** Правильное использование `async/await` и `waitFor`
4. **Type safety:** Все тесты написаны на TypeScript
5. **Realistic data:** Моки используют реалистичные данные

## Известные ограничения

1. **BackendSync интеграция:** Некоторые тесты требуют моки BackendSync
2. **Tauri Commands:** Все Tauri команды мокируются через `invoke`
3. **File System:** Файловая система мокируется, реальные файлы не используются
