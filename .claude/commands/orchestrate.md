# Оркестрация задачи через Swarm

Распредели и выполни задачу через рой агентов.

## Стратегии выполнения

- **parallel** - параллельное выполнение, все агенты работают одновременно
- **sequential** - последовательное выполнение, один за другим
- **adaptive** - адаптивное, система сама выбирает оптимальный путь

## Приоритеты

- **low** - низкий приоритет
- **medium** - средний приоритет (по умолчанию)
- **high** - высокий приоритет
- **critical** - критический приоритет

## Инструкция

1. Используй `mcp__ruv-swarm__task_orchestrate` с параметрами:
   - task: описание задачи
   - strategy: стратегия выполнения
   - priority: приоритет
   - maxAgents: количество агентов

2. Отслеживай прогресс через `mcp__ruv-swarm__task_status`

3. Получи результаты через `mcp__ruv-swarm__task_results`

## Формат аргументов
стратегия приоритет "описание задачи"

Пример: adaptive high "Проанализировать архитектуру проекта"
