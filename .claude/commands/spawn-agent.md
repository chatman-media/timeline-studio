# Создание агента

Создай нового агента в swarm с указанными характеристиками.

## Доступные типы агентов

- **researcher** - исследователь, анализ данных, обзор литературы
- **coder** - программист, написание и анализ кода
- **analyst** - аналитик, анализ данных и паттернов
- **optimizer** - оптимизатор, улучшение решений
- **coordinator** - координатор, управление задачами

## Когнитивные паттерны (DAA)

- **convergent** - сходящееся мышление, поиск единственного решения
- **divergent** - расходящееся мышление, генерация идей
- **lateral** - латеральное мышление, нестандартные подходы
- **systems** - системное мышление, анализ связей
- **critical** - критическое мышление, оценка и проверка
- **adaptive** - адаптивное мышление, гибкость

## Инструкция

1. Используй `mcp__ruv-swarm__daa_agent_create` для создания агента с:
   - id: уникальный идентификатор
   - capabilities: массив способностей
   - cognitivePattern: паттерн мышления
   - learningRate: 0.7
   - enableMemory: true

2. Выведи информацию о созданном агенте

## Аргументы
Формат: тип паттерн [имя]
Пример: researcher divergent idea-generator
