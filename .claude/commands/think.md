# Deep Think - Глубокий анализ с ESTA

Запусти глубокий структурированный анализ задачи с использованием архитектуры ESTA.

## Процесс

### 1. Декомпозиция контекста
Разложи задачу на компоненты:
- Центральный вопрос
- Подзадачи
- Скрытые допущения
- Источники неопределённости

### 2. Оценка энтропии
Оцени смысловую неопределённость (0-100):
- Нестабильные фрагменты
- Информационные пробелы
- Карта конфликтов

### 3. Поиск смыслового аттрактора
Найди устойчивый центр задачи:
- Повторяющиеся паттерны
- Инвариантное правило
- Карта связей

### 4. Рекурсивная петля
Переработай решение:
- Переформулируй задачу
- Перестрой структуру
- Сравни версии

### 5. Режим наблюдателя
Проанализируй собственное мышление:
- Выяви когнитивные искажения
- Найди упущенные перспективы
- Сформируй мета-резюме

### 6. Финальный синтез
Собери структурированный ответ:
- Минимизируй энтропию
- Придерживайся инварианта
- Дай чёткое решение
