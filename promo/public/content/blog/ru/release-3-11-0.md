# Timeline Studio 3.11.0 - Интеграция с MCP Tools

Timeline Studio 3.11.0 открывает новую эру интеграций благодаря поддержке Model Context Protocol (MCP) - теперь AI Chat может использовать 18 специализированных инструментов для работы с внешними сервисами!

## 🔌 Главная возможность

### 🛠️ 18 MCP Tools в AI Chat

Интеграция с Model Context Protocol от Anthropic:

- **Файловая система** - чтение, запись, поиск файлов
- **Git операции** - коммиты, ветки, история
- **Веб-запросы** - HTTP клиент для API
- **База данных** - работа с SQLite
- **Облачные сервисы** - интеграция с популярными платформами

### 🤖 IAITool адаптеры

Каждый MCP Tool обёрнут в IAITool интерфейс:

- **Единообразный интерфейс** для всех инструментов
- **Автоматическая валидация** параметров
- **Обработка ошибок** с понятными сообщениями
- **Документация** для каждого инструмента

### 💬 Умный AI Chat

AI теперь может выполнять сложные задачи:

```
Пользователь: "Найди все видео-файлы в проекте и создай для них резервные копии"

AI: Использует MCP Tools:
1. fs_search - поиск *.mp4, *.mov файлов
2. fs_copy - копирование в backup директорию
3. git_commit - коммит изменений

Результат: Все файлы скопированы и изменения сохранены в Git
```

## 🎯 Доступные инструменты

### Файловая система
- `fs_read` - чтение файлов
- `fs_write` - запись файлов
- `fs_list` - список файлов в директории
- `fs_search` - поиск файлов по паттерну

### Git
- `git_status` - статус репозитория
- `git_commit` - создание коммита
- `git_log` - история коммитов
- `git_diff` - изменения в файлах

### Веб
- `http_get` - GET запросы
- `http_post` - POST запросы
- `fetch_url` - загрузка контента

### Медиа
- `analyze_video` - анализ видео-файла
- `extract_audio` - извлечение аудио
- `generate_thumbnail` - создание превью

### Другие
- `sqlite_query` - SQL запросы
- `run_script` - выполнение скриптов
- `search_web` - поиск в интернете

## 🔧 Настройка

1. **Установите MCP Server** (опционально):
   ```bash
   npm install -g @anthropic/mcp-server
   ```

2. **Настройте инструменты** в Settings → AI Chat → MCP Tools

3. **Начинайте использовать** - просто спросите AI!
