# Timeline Studio Alpha v0.60.0: Полноценный видеоредактор с бесплатным локальным AI

*3 августа 2025*

Мы рады представить первый публичный альфа-релиз Timeline Studio — профессионального видеоредактора с революционным подходом к AI: **всё работает локально и бесплатно!**

## 🚀 Главная особенность: 100% локальный AI через Ollama

В то время как другие видеоредакторы требуют дорогие подписки на облачные AI-сервисы, Timeline Studio работает с **бесплатными локальными моделями Ollama**:

- **Никаких подписок** — используйте AI сколько угодно бесплатно
- **Полная приватность** — ваши данные никуда не отправляются
- **Работа офлайн** — не нужен интернет после загрузки моделей
- **Выбор моделей** — Llama 3.2, Phi-3, Gemma 2, Qwen 2.5 и другие

### Что умеет AI в альфа-версии:

- 📝 **Генерация субтитров** — автоматическая транскрипция и синхронизация
- 🎬 **Анализ видео** — определение сцен и ключевых моментов
- 🎯 **Smart подсказки** — AI помогает с монтажом
- 🔍 **Распознавание контента** — анализ композиции и качества кадров

## 🔧 Как начать работу

### 1. Установите Ollama (2 минуты)
```bash
# macOS
brew install ollama

# Linux  
curl -fsSL https://ollama.ai/install.sh | sh

# Windows
# Скачайте с https://ollama.ai/download/windows
```

### 2. Загрузите AI-модель (5 минут)
```bash
# Рекомендуемая лёгкая модель (1.6GB)
ollama pull gemma2:2b

# Запустите сервер
ollama serve
```
