# Выпуск Timeline Studio 2.6.0

Мы рады представить Timeline Studio 2.6.0 — крупное обновление с значительными улучшениями AI-редактирования, производительности и мультиплатформенного экспорта.

## Что нового

### 🤖 Улучшенная AI-интеграция
- Обновление до последней версии Claude API с улучшенным качеством ответов
- Новые алгоритмы AI-определения сцен
- Умные рекомендации контента на основе вашего стиля монтажа
- Автоматическая генерация субтитров с поддержкой 15 языков

### ⚡ Улучшения производительности
- На 40% быстрее рендеринг видео с оптимизированным GPU-конвейером
- Снижено использование памяти для больших проектов
- Улучшена производительность скроллинга таймлайна
- Лучшая обработка 4K и 8K материалов

### 🌍 Мультиплатформенный экспорт
- Прямая загрузка в TikTok, YouTube, Instagram и Facebook
- Пресеты оптимизации для конкретных платформ
- Автоматическое преобразование соотношения сторон
- Пакетный экспорт в несколько форматов

## Исправления ошибок

- Исправлены проблемы с синхронизацией аудио в мультикамерном режиме
- Устранены утечки памяти в длительных сессиях редактирования
- Улучшена стабильность работы с большими медиатеками
- Исправлен рендеринг субтитров для некоторых кодеков

## Получить обновление

Скачайте Timeline Studio 2.6.0 со [страницы релизов](https://github.com/chatman-media/timeline-studio/releases) или обновите напрямую из приложения.

Благодарим наше сообщество за постоянную поддержку и обратную связь!
