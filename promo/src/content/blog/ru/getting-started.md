# Начало работы с Timeline Studio

Добро пожаловать в Timeline Studio! Это руководство познакомит вас с основами и поможет создавать профессиональные видео за считанные минуты.

## Установка

### Системные требования

**Минимальные:**
- Windows 10/11, macOS 10.15+ или Linux
- 8GB RAM
- 2GB свободного места на диске
- GPU с поддержкой OpenGL 3.3+

**Рекомендуемые:**
- 16GB+ RAM
- NVIDIA GPU с NVENC или AMD GPU с VCE
- SSD для файлов проекта

### Загрузка и установка

1. Посетите [timelinestudio.pro](https://timelinestudio.pro)
2. Скачайте версию для вашей платформы
3. Запустите установщик
4. Откройте Timeline Studio

## Первый проект

### Создание нового проекта

1. Нажмите "Новый проект" на экране приветствия
2. Задайте имя проекта и разрешение
3. Выберите частоту кадров (24, 30 или 60 fps)
4. Укажите место сохранения

### Импорт медиа

Timeline Studio поддерживает все основные форматы видео:

- **Видео:** MP4, MOV, AVI, MKV, WebM
- **Аудио:** MP3, WAV, AAC, FLAC
- **Изображения:** JPG, PNG, WebP, SVG

**Три способа импорта:**
1. Перетащите файлы в Медиа-браузер
2. Нажмите кнопку "Импорт медиа"
3. Используйте меню Файл → Импорт

### Основы редактирования

#### Таймлайн

Таймлайн — это место, где вы собираете своё видео:

- **Видеодорожки** - Для видеоклипов и изображений
- **Аудиодорожки** - Для аудио и музыки
- **Курсор воспроизведения** - Показывает текущий кадр

#### Добавление клипов

1. Перетащите медиа из браузера на таймлайн
2. Разместите в нужной позиции
3. Обрежьте, потянув за края клипа
4. Разделите инструментом ножниц (клавиша C)

#### Основные операции

- **Разрезать:** Выберите клип, нажмите C для разделения на позиции курсора
- **Удалить:** Выберите клип, нажмите Delete
- **Переместить:** Перетащите клип в новую позицию
- **Обрезать:** Потяните за края клипа для изменения длительности

## Основные функции

### Эффекты и фильтры

Добавляйте визуальные эффекты из панели Эффектов:
- Цветокоррекция
- Размытие и резкость
- Креативные фильтры
- Кастомные шейдеры

### Переходы

Плавные переходы между клипами:
1. Перетащите переход из панели Переходов
2. Разместите между двумя клипами
3. Настройте длительность
4. Измените параметры

### Сведение аудио

Timeline Studio включает профессиональные аудиоинструменты:
- Многодорожечное сведение
- Эффекты в реальном времени
- Автоматизация громкости
- Шумоподавление

### Субтитры

Легко добавляйте субтитры:
1. Откройте панель Субтитры
2. Нажмите "Добавить субтитр"
3. Введите текст
4. Настройте тайминг
5. Измените стиль

## Экспорт видео

### Быстрый экспорт

1. Нажмите "Экспорт" в верхнем меню
2. Выберите пресет (YouTube, TikTok и т.д.)
3. Выберите качество
4. Нажмите "Начать экспорт"

### Кастомный экспорт

Для продвинутых пользователей:
- Выберите кодек (H.264, H.265, ProRes)
- Установите битрейт
- Настройте параметры аудио
- Добавьте метаданные

## Горячие клавиши

Изучите эти комбинации для ускорения монтажа:

- **Пробел:** Воспроизведение/Пауза
- **C:** Разделить клип на позиции курсора
- **Delete:** Удалить выбранный клип
- **Ctrl+Z:** Отменить
- **Ctrl+S:** Сохранить проект
- **Ctrl+E:** Экспорт

## Следующие шаги

Теперь, когда вы знаете основы:

1. Изучите AI-функции для умного монтажа
2. Попробуйте разные эффекты и переходы
3. Экспериментируйте с цветокоррекцией
4. Посмотрите наши видеоуроки

Приятного монтажа!
