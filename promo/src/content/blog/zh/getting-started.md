# Timeline Studio 入门指南

欢迎使用 Timeline Studio！本指南将引导您了解基础知识，并在几分钟内开始创建专业视频。

## 安装

### 系统要求

**最低配置:**
- Windows 10/11、macOS 10.15+ 或 Linux
- 8GB RAM
- 2GB 可用磁盘空间
- 支持 OpenGL 3.3+ 的GPU

**推荐配置:**
- 16GB+ RAM
- 支持NVENC的NVIDIA GPU或支持VCE的AMD GPU
- 用于项目文件的SSD

### 下载和安装

1. 访问 [timelinestudio.pro](https://timelinestudio.pro)
2. 下载适合您平台的版本
3. 运行安装程序
4. 启动 Timeline Studio

## 第一个项目

### 创建新项目

1. 在欢迎屏幕上点击"新建项目"
2. 设置项目名称和分辨率
3. 选择帧率（24、30或60 fps）
4. 选择保存位置

### 导入媒体

Timeline Studio 支持所有主要视频格式:

- **视频:** MP4、MOV、AVI、MKV、WebM
- **音频:** MP3、WAV、AAC、FLAC
- **图像:** JPG、PNG、WebP、SVG

**导入的三种方式:**
1. 将文件拖放到媒体浏览器
2. 点击"导入媒体"按钮
3. 使用文件 → 导入菜单

### 基础编辑

#### 时间线

时间线是您组装视频的地方:

- **视频轨道** - 用于视频剪辑和图像
- **音频轨道** - 用于音频和音乐
- **播放头** - 显示当前帧

#### 添加剪辑

1. 从浏览器拖动媒体到时间线
2. 放置到所需位置
3. 通过拖动剪辑边缘修剪
4. 使用剪刀工具分割（C键）

#### 常用操作

- **剪切:** 选择剪辑，按C在播放头处分割
- **删除:** 选择剪辑，按Delete
- **移动:** 拖动剪辑到新位置
- **修剪:** 拖动剪辑边缘调整时长

## 基本功能

### 效果和滤镜

从效果面板添加视觉效果:
- 色彩校正
- 模糊和锐化
- 创意滤镜
- 自定义着色器

### 转场

剪辑之间的平滑转场:
1. 从转场面板拖动转场
2. 放置在两个剪辑之间
3. 调整持续时间
4. 自定义属性

### 音频混音

Timeline Studio 包含专业音频工具:
- 多轨混音
- 实时效果
- 音量自动化
- 降噪

### 字幕

轻松添加字幕:
1. 打开字幕面板
2. 点击"添加字幕"
3. 输入文本
4. 调整时间
5. 自定义样式

## 导出视频

### 快速导出

1. 点击顶部菜单中的"导出"
2. 选择预设（YouTube、TikTok等）
3. 选择质量
4. 点击"开始导出"

### 自定义导出

适合高级用户:
- 选择编解码器（H.264、H.265、ProRes）
- 设置比特率
- 配置音频设置
- 添加元数据

## 键盘快捷键

学习这些快捷键以加快编辑速度:

- **空格键:** 播放/暂停
- **C:** 在播放头处分割剪辑
- **Delete:** 删除选定剪辑
- **Ctrl+Z:** 撤销
- **Ctrl+S:** 保存项目
- **Ctrl+E:** 导出
