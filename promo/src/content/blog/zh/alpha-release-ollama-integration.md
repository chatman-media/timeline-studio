## 📦 如何开始

### 1. 安装本地AI运行时（5分钟）
```bash
# macOS/Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows
# 从 https://ollama.com/download 下载
```

### 2. 下载AI模型（3-5分钟）
```bash

# 或更轻量的版本
ollama pull phi3
```

### 3. 启动Timeline Studio
只需打开应用程序——它会自动检测本地AI和可用模型！
