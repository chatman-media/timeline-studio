# Getting Started with Timeline Studio

Welcome to Timeline Studio! This guide will walk you through the basics and get you creating professional videos in minutes.

## Installation

### System Requirements

**Minimum:**
- Windows 10/11, macOS 10.15+, or Linux
- 8GB RAM
- 2GB free disk space
- OpenGL 3.3+ compatible GPU

**Recommended:**
- 16GB+ RAM
- NVIDIA GPU with NVENC or AMD GPU with VCE
- SSD for project files

### Download & Install

1. Visit [timelinestudio.pro](https://timelinestudio.pro)
2. Download for your platform
3. Run the installer
4. Launch Timeline Studio

## First Project

### Creating a New Project

1. Click "New Project" on the welcome screen
2. Set project name and resolution
3. Choose frame rate (24, 30, or 60 fps)
4. Select save location

### Importing Media

Timeline Studio supports all major video formats:

- **Video:** MP4, MOV, AVI, MKV, WebM
- **Audio:** MP3, WAV, AAC, FLAC
- **Images:** JPG, PNG, WebP, SVG

**Three ways to import:**
1. Drag & drop files into the Media Browser
2. Click "Import Media" button
3. Use File → Import menu

### Basic Editing

#### The Timeline

The timeline is where you assemble your video:

- **Video tracks** - For video clips and images
- **Audio tracks** - For audio and music
- **Playhead** - Shows current frame

#### Adding Clips

1. Drag media from browser to timeline
2. Drop at desired position
3. Trim by dragging clip edges
4. Split with scissors tool (C key)

#### Common Operations

- **Cut:** Select clip, press C to split at playhead
- **Delete:** Select clip, press Delete
- **Move:** Drag clip to new position
- **Trim:** Drag clip edges to adjust duration

## Essential Features

### Effects & Filters

Add visual effects from the Effects panel:
- Color correction
- Blur and sharpen
- Creative filters
- Custom shaders

### Transitions

Smooth transitions between clips:
1. Drag transition from Transitions panel
2. Drop between two clips
3. Adjust duration
4. Customize properties

### Audio Mixing

Timeline Studio includes professional audio tools:
- Multi-track mixing
- Real-time effects
- Volume automation
- Noise reduction

### Subtitles

Add subtitles easily:
1. Open Subtitles panel
2. Click "Add Subtitle"
3. Type text
4. Adjust timing
5. Customize styling

## Exporting Your Video

### Quick Export

1. Click "Export" in top menu
2. Choose preset (YouTube, TikTok, etc.)
3. Select quality
4. Click "Start Export"

### Custom Export

For advanced users:
- Choose codec (H.264, H.265, ProRes)
- Set bitrate
- Configure audio settings
- Add metadata

## Keyboard Shortcuts

Learn these shortcuts to speed up editing:

- **Space:** Play/Pause
- **C:** Split clip at playhead
- **Delete:** Remove selected clip
- **Ctrl+Z:** Undo
- **Ctrl+S:** Save project
- **Ctrl+E:** Export
