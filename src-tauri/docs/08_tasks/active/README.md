# Активные задачи / Active Tasks

Этот каталог содержит текущие активные задачи разработки Timeline Studio.

## Структура

- **active/** - Активные задачи в процессе выполнения
- **completed/** - Завершенные задачи (для справки)
- **archived/** - Архивированные задачи

## Формат задач

Каждая задача должна содержать:
- Название и описание
- Текущий статус и прогресс
- Следующие шаги
- История изменений
