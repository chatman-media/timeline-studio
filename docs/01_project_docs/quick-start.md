## 📥 Клонирование репозитория

```bash
# Клонирование репозитория
git clone https://github.com/your-org/timeline-studio.git
cd timeline-studio

# Проверка структуры
ls -la
```

Вы должны увидеть следующую структуру:
```
timeline-studio/
├── src/                # Frontend код (React)
├── src-tauri/          # Backend код (Rust)
├── public/             # Статические файлы
├── docs-ru/            # Документация
├── package.json        # NPM конфигурация
├── tauri.conf.json     # Tauri конфигурация
└── ...
```

## 📦 Установка зависимостей

### 1. Frontend зависимости

```bash
# Установка npm пакетов через Bun
bun install

# Или через npm (медленнее)
npm install
```

### 2. Backend зависимости

```bash
# Rust зависимости устанавливаются автоматически при первой сборке
# Но можно запустить вручную:
cd src-tauri
cargo build
cd ..
```

### 3. Дополнительные зависимости для AI-функций

#### macOS
```bash
# Установка ONNX Runtime для распознавания объектов
brew install onnxruntime

# Добавьте в ~/.zshrc или ~/.bashrc:
export ORT_DYLIB_PATH=/opt/homebrew/lib/libonnxruntime.dylib
```

#### Windows
```powershell
# ONNX Runtime устанавливается автоматически через vcpkg
# или скачайте с https://github.com/microsoft/onnxruntime/releases
```

#### Linux
```bash
# Установка ONNX Runtime
sudo apt-get install libonnxruntime-dev
# или через snap:
sudo snap install onnxruntime
```

## 🚀 Запуск приложения

### Режим разработки

```bash
# Запуск с hot-reload для frontend и backend
bun run tauri dev

# Или только frontend (без Tauri функций)
bun run dev
```

После запуска откроется окно приложения Timeline Studio.

### Проверка работоспособности

1. Приложение должно открыться без ошибок
2. В консоли не должно быть критических ошибок
3. Интерфейс должен быть отзывчивым

## 🎬 Создание видео проекта

### Шаг 1: Создание нового проекта

1. Нажмите **"Файл" → "Новый проект"** или `Ctrl/Cmd + N`
2. Введите название проекта (например, "Мой первый проект")
3. Выберите настройки:
   - **Разрешение**: 1920x1080 (Full HD)
   - **FPS**: 30 кадров в секунду
   - **Соотношение сторон**: 16:9

### Шаг 2: Импорт медиафайлов

1. Откройте вкладку **"Медиа"** в браузере
2. Нажмите **"Импорт"** или перетащите файлы в окно
3. Поддерживаемые форматы:
   - Видео: MP4, MOV, AVI, MKV, WebM
   - Аудио: MP3, WAV, AAC, OGG
   - Изображения: JPG, PNG, GIF, WebP

### Шаг 3: Добавление на таймлайн

```
Браузер медиа                    Таймлайн
┌─────────────┐                 ┌──────────────────────┐
│ video1.mp4  │ ──перетащить──> │ [====видео====]      │
│ audio1.mp3  │                 │     [==аудио==]      │
│ image1.jpg  │                 │ [изображение]        │
└─────────────┘                 └──────────────────────┘
```

1. Перетащите видео из браузера на видео-трек таймлайна
2. Перетащите аудио на аудио-трек
3. Изображения можно добавить на любой видео-трек

## 🛠️ Основные операции

### Обрезка клипов

1. Выберите клип на таймлайне
2. Наведите курсор на край клипа
3. Перетащите край для обрезки

```
До:    [============клип============]
После: [======клип======]
```

### Разделение клипов

1. Установите плейхед в нужное место
2. Нажмите **"S"** или кнопку "Разделить"

```
До:    [============клип============]
       ↑ плейхед
После: [======][======]
```

### Добавление переходов

1. Перейдите во вкладку **"Переходы"**
2. Перетащите переход между двумя клипами
3. Настройте длительность перехода

### Применение эффектов

1. Выберите клип
2. Откройте вкладку **"Эффекты"**
3. Дважды щелкните на эффект или перетащите на клип
4. Настройте параметры в панели свойств

### Добавление текста

1. Перейдите в **"Титры"**
2. Выберите шаблон текста
3. Перетащите на таймлайн
4. Дважды щелкните для редактирования

## 🎯 Продвинутые функции

### AI-функции

#### AI Content Intelligence
Интеллектуальный анализ контента с использованием искусственного интеллекта:

- **Автоматическое распознавание сцен** - детекция смены сцен и ключевых кадров
- **Распознавание объектов** - идентификация объектов в видео (YOLO/ONNX)
- **Генерация скриптов** - автоматическое создание описаний и диалогов
- **Адаптация под платформы** - оптимизация контента для YouTube, TikTok, Instagram
- **OCR** - распознавание текста в видео

#### Smart Montage Planner с Unified Audio Analysis
AI-планировщик монтажа для автоматического создания профессиональных видео:

- **Анализ материалов** - автоматический анализ всех импортированных файлов
- **🆕 Unified Audio Analysis** - f64 precision аудио анализ с Whisper integration
- **Генерация планов** - создание монтажных планов в различных стилях
- **Детекция лучших моментов** - автоматический поиск интересных кадров
- **Рекомендации по ритму** - подбор оптимального темпа монтажа
- **Интеграция с Timeline** - применение плана одним кликом

#### Person Identification
Система распознавания и идентификации персонажей:

- **Автоматическая детекция лиц** - поиск всех лиц в видео
- **Идентификация персонажей** - сопоставление с известными профилями
- **Управление профилями** - создание и редактирование карточек персонажей
- **Статистика появлений** - анализ экранного времени каждого персонажа
- **Интеграция с Timeline** - отметки персонажей на клипах

### Профессиональные инструменты

#### Fairlight Audio + Unified Audio Analysis
Профессиональный аудио микшер с полным набором инструментов:

- **7-полосный параметрический эквалайзер** - точная настройка частот
- **Эффекты** - компрессор, реверберация, AI шумоподавление
- **Surround Sound** - поддержка Stereo, 5.1, 7.1
- **MIDI интеграция** - полная поддержка MIDI контроллеров
- **Профессиональные измерители** - LUFS, спектроанализатор, фазометр
- **🆕 Unified Audio Analysis** - f64 precision анализ с comprehensive error handling
- **🆕 Whisper Integration** - автоматическая транскрипция речи

#### Color Grading
Профессиональная цветокоррекция уровня DaVinci Resolve:

- **Цветовые колеса** - Lift/Gamma/Gain/Offset
- **Кривые** - RGB и тональные кривые с Bézier интерполяцией
- **HSL настройки** - температура, оттенок, контраст, насыщенность
- **Поддержка LUT** - импорт .cube файлов
- **Профессиональные скоупы** - Waveform, Vectorscope, Histogram

#### Motion Graphics
Система анимации на основе ключевых кадров:

- **Полноценная система ключевых кадров** - анимация любых параметров
- **Типы интерполяции** - Linear, Bezier, Ease, Bounce, Elastic
- **Expression engine** - JavaScript для процедурной анимации
- **Готовые пресеты** - библиотека анимационных эффектов
- **Визуальный редактор кривых** - точная настройка анимации

### Дополнительные возможности

#### Multicam - Многокамерная съемка
Профессиональная работа с многокамерными проектами:

- **Быстрое переключение** - горячие клавиши 1-9 для смены углов
- **Синхронизация** - по таймкоду или аудио
- **Визуальная сетка** - превью всех камер одновременно
- **Ручная настройка** - корректировка смещения для каждой камеры
- **Связанные клипы** - автоматическая синхронизация на таймлайне

#### Camera Capture - Захват с камеры
Запись видео непосредственно в Timeline Studio:

- **Выбор устройств** - камера и микрофон из доступных
- **Настройки качества** - разрешение и FPS
- **Запись экрана** - захват экрана, окна или вкладки браузера
- **Превью в реальном времени** - контроль записи
- **Формат WebM** - оптимальное качество и размер

#### Voice Recording - Запись голоса
Профессиональная запись закадрового голоса:

- **Выбор микрофона** - из всех доступных устройств
- **Обратный отсчет** - от 0 до 10 секунд перед записью
- **Визуальные индикаторы** - уровень сигнала и время записи
- **До 5 минут** - оптимально для комментариев
- **Автосохранение** - сразу в медиатеку проекта

## 📤 Экспорт видео

### Быстрый экспорт

1. Нажмите **"Файл" → "Экспорт"** или `Ctrl/Cmd + E`
2. Выберите пресет:
   - **YouTube 1080p** - оптимально для YouTube
   - **Социальные сети** - для Instagram/TikTok
   - **Высокое качество** - максимальное качество

### Настраиваемый экспорт

```javascript
// Пример настроек экспорта
{
  format: "mp4",
  codec: "h264",
  resolution: "1920x1080",
  fps: 30,
  bitrate: "10M",
  audioCodec: "aac",
  audioBitrate: "192k"
}
```

### Процесс экспорта

1. Выберите папку для сохранения
2. Введите имя файла
3. Нажмите **"Экспорт"**
4. Дождитесь завершения (прогресс отображается)
