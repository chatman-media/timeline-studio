## 🖥️ Установка и настройка

### Windows 10/11

#### 1. Системные требования
- **ОС**: Windows 10 версия 1809+ или Windows 11
- **RAM**: минимум 8GB, рекомендуется 16GB
- **Место на диске**: 10GB свободного места
- **Процессор**: 4 ядра, 2.5GHz+
- **GPU**: DirectX 11 совместимая (опционально для ускорения)

#### 2. Установка Timeline Studio
```powershell
# 1. Скачать установщик с GitHub Releases
# https://github.com/chatman-media/timeline-studio/releases/tag/v0.60.0-alpha

# 2. Запустить установщик (Timeline-Studio-Setup-0.60.0.exe)
# 3. Следовать инструкциям установщика
# 4. Приложение установится в C:\Program Files\Timeline Studio
```

#### 3. Установка Ollama (для AI функций)
```powershell
# Скачать установщик Ollama
# https://ollama.ai/download/windows

# После установки открыть PowerShell и выполнить:
ollama pull llama3.2

# Проверить что Ollama работает:
ollama list
```

#### 4. Первый запуск
1. Запустить Timeline Studio из меню Пуск
2. При первом запуске выбрать язык интерфейса
3. Проверить подключение к Ollama (должно быть автоматически)
4. Создать тестовый проект

### macOS 12+

#### 1. Системные требования
- **ОС**: macOS 12 Monterey или новее
- **RAM**: минимум 8GB, рекомендуется 16GB  
- **Место на диске**: 10GB свободного места
- **Процессор**: Apple Silicon (M1/M2/M3) или Intel
- **GPU**: Metal совместимая (встроенная)

#### 2. Установка Timeline Studio
```bash
# 1. Скачать DMG файл с GitHub Releases
# https://github.com/chatman-media/timeline-studio/releases/tag/v0.60.0-alpha

# 2. Открыть Timeline-Studio-0.60.0.dmg
# 3. Перетащить в папку Applications
# 4. При первом запуске: правый клик → Открыть (обход Gatekeeper)
```

#### 3. Установка Ollama
```bash
# Через Homebrew
brew install ollama

# Запустить Ollama сервер
ollama serve

# В новом терминале скачать модель
ollama pull llama3.2

# Проверить установку
ollama list
```

#### 4. Первый запуск
1. Открыть Timeline Studio из Launchpad или Applications
2. Разрешить доступ к камере/микрофону если спросит
3. Выбрать язык интерфейса
4. Создать тестовый проект

## 📋 Тестовые сценарии

### Сценарий 1: Базовый монтаж видео
**Цель**: Проверить основную функциональность редактирования

1. **Импорт медиа**
   - [ ] Создать новый проект

   - [ ] Проверить превью в медиа браузере
   - [ ] Перетащить файлы на timeline

2. **Редактирование**
   - [ ] Обрезать клипы (trim)
   - [ ] Переставить клипы местами
   - [ ] Добавить переход между клипами

   - [ ] Экспортировать в MP4 (1080p)
   - [ ] Проверить качество результата

**Ожидаемый результат**: Все операции выполняются без сбоев, экспорт успешен

### Сценарий 2: AI анализ видео с Ollama
**Цель**: Проверить интеграцию с локальным AI

1. **Подготовка**
   - [ ] Убедиться что Ollama запущена (`ollama serve`)

   - [ ] Загрузить видео с говорящими людьми

2. **Анализ контента**
   - [ ] Открыть AI Content Intelligence
   - [ ] Выбрать видео для анализа
   - [ ] Запустить "Анализ сцен"
   - [ ] Дождаться результатов (может занять 1-3 минуты)

3. **Результаты**
   - [ ] Проверить детекцию сцен
   - [ ] Проверить ключевые моменты
   - [ ] Экспортировать результаты в JSON
   - [ ] Сохранить отчет

**Ожидаемый результат**: AI успешно анализирует видео и генерирует метаданные

### Сценарий 3: Генерация субтитров
**Цель**: Проверить автоматическую генерацию субтитров

1. **Подготовка**
   - [ ] Загрузить видео с четкой речью (русский/английский)
   - [ ] Длительность 2-5 минут

2. **Генерация**
   - [ ] Выбрать "Генерация субтитров" в AI меню
   - [ ] Выбрать язык
   - [ ] Запустить процесс
   - [ ] Дождаться завершения

3. **Проверка и экспорт**
   - [ ] Просмотреть субтитры на timeline
   - [ ] Исправить ошибки если есть
   - [ ] Экспортировать в SRT формат
   - [ ] Проверить тайминги

**Ожидаемый результат**: Субтитры генерируются с приемлемой точностью

### Сценарий 4: Стресс-тест производительности
**Цель**: Проверить стабильность при нагрузке

1. **Большой проект**
   - [ ] Импортировать 20+ видео файлов
   - [ ] Создать timeline с 50+ клипами
   - [ ] Добавить эффекты к 10+ клипам
   - [ ] Работать 30+ минут без перезапуска

2. **Мониторинг**
   - [ ] Следить за использованием RAM
   - [ ] Проверить температуру CPU
   - [ ] Засечь время операций
   - [ ] Отметить любые зависания

**Ожидаемый результат**: Приложение остается стабильным

## 📊 Как собирать информацию

### Логи приложения

#### Windows
```powershell
# Логи находятся в:
%APPDATA%\timeline-studio\logs\

# Скопировать последний лог:
copy "%APPDATA%\timeline-studio\logs\*.log" Desktop\
```

#### macOS
```bash
# Логи находятся в:
~/Library/Application Support/timeline-studio/logs/

# Скопировать последний лог:
cp ~/Library/Application\ Support/timeline-studio/logs/*.log ~/Desktop/
```

## ❓ FAQ

**Q: Ollama не подключается, что делать?**
A: Проверьте что Ollama запущена (`ollama serve`), перезапустите Timeline Studio.

**Q: Приложение тормозит с большими файлами?**
A: Это известная проблема альфа-версии. Попробуйте уменьшить разрешение превью в настройках.

**Q: Можно ли использовать другие AI модели?**
A: Да! Попробуйте `ollama pull gemma2:2b` для более быстрой модели.

**Q: Экспорт зависает на 99%?**
A: Подождите, финализация может занять время. Если более 10 минут - это баг.

**Q: Где взять тестовые видео?**
A: Можете использовать любые свои видео или скачать примеры с Pexels/Pixabay.
