## Системные требования

### macOS 12+
- **RAM**: минимум 8GB, рекомендуется 16GB
- **Место на диске**: 10GB свободного места
- **Процессор**: Apple Silicon (M1/M2/M3/M4) или Intel
- **GPU**: Metal совместимая (встроенная)

### Windows 10/11
- **RAM**: минимум 8GB, рекомендуется 16GB
- **Место на диске**: 10GB свободного места
- **Процессор**: 4 ядра, 2.5GHz+
- **GPU**: DirectX 11 совместимая

## Установка

### 1. Timeline Studio

```bash
# macOS - скачать DMG с GitHub Releases
# https://github.com/chatman-media/timeline-studio/releases

# Windows - скачать MSI установщик
```

### 2. Ollama (для локального AI)

```bash
# macOS
brew install ollama

# Запустить сервис
ollama serve

# Скачать модели для vision анализа
ollama pull moondream2     # 1.7 GB - быстрая
ollama pull llava          # 4.7 GB - качественная
ollama pull llama3.2-vision # 7.9 GB - новейшая

# Для чата
ollama pull llama3.2       # текстовая модель

# Проверить установку
ollama list
```

### 3. Первый запуск

1. Запустить Timeline Studio
2. Выбрать язык интерфейса (15 языков доступно)
3. Проверить подключение к Ollama в Settings → API Keys
4. Создать тестовый проект

## Что искать (частые проблемы)

### Критические баги
- Крэши приложения
- Потеря данных проекта
- Невозможность экспорта
- Зависания более 30 секунд

### Важные баги
- Рассинхрон аудио/видео
- Артефакты при рендеринге
- Неправильная работа эффектов
- Проблемы с Ollama подключением
- VLM не анализирует кадры

### Минорные баги
- UI глюки и артефакты
- Неточности в переводах (15 языков)
- Медленная производительность
- Неудобства в UX

## FAQ

**Q: Ollama не подключается?**
A: Проверьте что запущена (`ollama serve`), перезапустите Timeline Studio.

**Q: VLM анализ медленный?**
A: Используйте `moondream2` вместо `llava`. Убедитесь что есть GPU.

**Q: Какую модель выбрать для vision?**
A: `moondream2` для скорости, `llava` для качества, `llama3.2-vision` для новейших возможностей.

**Q: Можно использовать без интернета?**
A: Да! С Ollama и локальными моделями Timeline Studio работает полностью оффлайн.

**Q: Экспорт зависает на 99%?**
A: Подождите, финализация может занять время. Если более 10 минут - это баг.
