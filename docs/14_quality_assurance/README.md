## 🧪 Что тестировать в альфа-версии

### Приоритет 1 (Критично)
1. **Запуск приложения** на разных платформах
2. **Ollama интеграция** - подключение и работа AI
3. **Базовый монтаж** - timeline, импорт медиа
4. **Экспорт видео** - основные форматы

### Приоритет 2 (Важно)
1. **AI анализ видео** - детекция сцен
2. **Генерация субтитров** через Ollama
3. **Эффекты и переходы** - применение и превью
4. **Сохранение проектов** - загрузка и сохранение

### Приоритет 3 (Желательно)
1. **Производительность** с большими файлами
2. **Многоязычность** - переключение языков
3. **Горячие клавиши** и shortcuts
4. **UI/UX** - удобство интерфейса

## 🐛 Известные проблемы альфа-версии

### Не блокирующие
1. **TypeScript ошибки** (~1860) - не влияют на работу
2. **Первый запрос к Ollama медленный** - загрузка модели
3. **Нет GPU ускорения для Ollama** - только CPU

### Требуют внимания
1. **Использование памяти** с большими проектами
2. **Стабильность** при длительной работе
3. **Совместимость** форматов видео

## 👥 Для тестировщиков

### Минимальные требования
- **ОС**: Windows 10/11, macOS 12+, Linux Ubuntu 22.04+
- **RAM**: 8GB минимум, 16GB рекомендуется
- **Место на диске**: 10GB свободного места
- **Процессор**: 4 ядра минимум
- **Ollama**: установлена и настроена (для AI функций)

### Как начать тестирование
1. Скачать альфа-версию из [GitHub Releases](https://github.com/chatman-media/timeline-studio/releases)
2. Установить Ollama: https://ollama.ai
3. Скачать модель: `ollama pull llama3.2`
4. Запустить Timeline Studio
5. Следовать тестовым сценариям
