# Руководство по безопасности Timeline Studio

*Версия: 0.60.0-alpha | Обновлено: 3 августа 2025*

## 🔒 Обзор безопасности альфа-версии

Timeline Studio альфа-версия включает базовые меры безопасности. Полная реализация безопасности запланирована на beta и production релизы.

## 🛡️ Текущие меры безопасности

### 1. Архитектура приложения

#### Tauri v2 Security
- **Изоляция процессов**: Frontend и backend изолированы
- **IPC безопасность**: Все команды проходят валидацию
- **CSP (Content Security Policy)**: Ограничение загрузки внешних ресурсов
- **Песочница**: Приложение работает в изолированной среде

#### Права доступа
```json
{
  "permissions": [
    "path:default",
    "shell:allow-open",
    "fs:allow-read",
    "fs:allow-write",
    "fs:allow-exists",
    "dialog:default",
    "clipboard:default",
    "notification:default"
  ]
}
```

### 2. Обработка данных

#### Локальное хранение
- **Проекты**: Хранятся локально в формате JSON
- **Медиафайлы**: Ссылки, не копии файлов
- **Настройки**: В локальном хранилище приложения
- **Кэш**: Временные файлы в системной папке temp

#### AI интеграция (Ollama)
- **Локальная обработка**: Все AI модели работают локально
- **Без отправки данных**: Видео не загружаются в облако
- **Изоляция моделей**: Каждая модель работает в своем процессе
- **Контроль ресурсов**: Ограничение использования CPU/RAM

### 3. Сетевая безопасность

#### Текущие соединения
- **GitHub API**: Проверка обновлений (HTTPS)
- **Ollama API**: Локальный порт 11434 (HTTP localhost)
- **Будущее**: OpenAI/Anthropic API (HTTPS)

#### Безопасность API ключей
```typescript
// Хранение в зашифрованном виде
const encryptedKey = await encrypt(apiKey, userPassword);
localStorage.setItem('ai_api_key', encryptedKey);

// Использование переменных окружения
const apiKey = import.meta.env.VITE_OPENAI_API_KEY;
```

### 4. Валидация входных данных

#### Проверка файлов
```typescript
// Валидация медиафайлов
const ALLOWED_VIDEO_FORMATS = ['.mp4', '.mov', '.avi', '.mkv', '.webm'];
const MAX_FILE_SIZE = 10 * 1024 * 1024 * 1024; // 10GB

function validateVideoFile(file: File): boolean {
  const extension = path.extname(file.name).toLowerCase();
  if (!ALLOWED_VIDEO_FORMATS.includes(extension)) {
    throw new Error('Неподдерживаемый формат файла');
  }
  if (file.size > MAX_FILE_SIZE) {
    throw new Error('Файл слишком большой');
  }
  return true;
}
```

#### Санитизация пользовательского ввода
```typescript
// Очистка текста для субтитров
import DOMPurify from 'dompurify';

function sanitizeSubtitle(text: string): string {
  return DOMPurify.sanitize(text, {
    ALLOWED_TAGS: [],
    ALLOWED_ATTR: []
  });
}
```

## 🚨 Известные уязвимости альфа-версии

### Требуют внимания перед beta
1. **API ключи**: Временно хранятся в localStorage (нужна миграция на secure storage)
2. **Проверка MIME типов**: Только проверка расширений файлов
3. **Rate limiting**: Отсутствует для API запросов
4. **Логирование**: Может содержать чувствительные данные

### Будут исправлены в production
1. **Шифрование проектов**: Опциональное шифрование файлов проекта
2. **2FA**: Двухфакторная аутентификация для облачных функций
3. **Аудит логи**: Полное логирование действий пользователя
4. **Secure storage**: Использование системного хранилища ключей

## 🔐 Рекомендации для пользователей

### Базовая безопасность
1. **Обновления**: Всегда устанавливайте последние версии
2. **Источники файлов**: Используйте только доверенные видеофайлы
3. **API ключи**: Не делитесь ключами, используйте отдельные для тестирования
4. **Резервные копии**: Регулярно сохраняйте проекты

### Ollama безопасность
```bash
# Проверьте что Ollama слушает только localhost
ollama serve --host 127.0.0.1

# Не открывайте порт для внешних подключений
# НЕ ДЕЛАЙТЕ: ollama serve --host 0.0.0.0
```

### Защита проектов
1. Храните проекты в защищенных папках
2. Используйте шифрование диска (BitLocker/FileVault)
3. Не открывайте проекты из неизвестных источников
4. Проверяйте медиафайлы антивирусом
