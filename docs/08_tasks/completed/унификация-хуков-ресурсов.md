## Проблема

В Timeline Studio существует дублирование логики между различными системами работы с ресурсами:

1. **Feature-хуки** - загружают ресурсы напрямую из JSON файлов
2. **Browser-хуки** - работают через унифицированный EffectsProvider  
3. **Resources Panel** - отдельная панель ресурсов в другом модуле
4. **Import-хуки** - специализированные хуки для импорта пользовательских ресурсов

Это создает конфликты имен, дублирование кода и сложность в поддержке.

## Типы ресурсов

Необходимо унифицировать работу со всеми типами ресурсов:

- **Effects** (эффекты)
- **Filters** (фильтры) 
- **Transitions** (переходы)
- **Templates** (шаблоны)
- **Style Templates** (стилистические шаблоны)
- **Media** (медиафайлы)
- **Music** (музыка)
- **Subtitles** (субтитры)

## Решение

### Архитектурный подход

Использовать существующий `useResourcesAdapter` как базу для унифицированной системы:

```typescript
// Единый конфигурируемый хук
function useResourcesAdapter(type: ResourceType, options: SearchOptions = {}) {
  // Уже реализован в use-resources.ts:353
}

// Типизированные обертки
export const useEffectsAdapter = (options?) => useResourcesAdapter("effect", options)
export const useFiltersAdapter = (options?) => useResourcesAdapter("filter", options)
export const useTransitionsAdapter = (options?) => useResourcesAdapter("transition", options)
```

   - Все адаптеры используют DragDropManager через `useDraggable`
   - Консистентная структура превью компонентов (list/grid режимы)
   - Правильная типизация с type assertion для каждого ресурса

4. **Обратная совместимость**
   - Старые адаптеры экспортируются как `useEffectsListAdapter`, `useFiltersListAdapter`
   - Feature-хуки не изменены и продолжают работать внутри модулей
