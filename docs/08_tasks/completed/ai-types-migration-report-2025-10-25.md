### 2. Миграция провайдеров

#### ✅ TimelineProviders
- **Статус до:** Частичная интеграция через Orchestrator
- **Статус после:** Полная интеграция с BackendSync
- **Детали:** Все команды синхронизируются с backend через `backendSync.executeCommand()`

#### ✅ MediaManagementProvider
- **Статус до:** Локальное состояние без интеграции
- **Статус после:** Полная интеграция с BackendSync
- **Детали:** 
  - Импорт файлов через `AppCommands.addMedia()`
  - Синхронизация состояния через `onStateChange`
  - Обновление метаданных через `AppCommands.updateMedia()`

#### ✅ BrowserDomainProvider
- **Статус:** Проанализирован, определен как UI-only провайдер
- **Решение:** Не требует интеграции с BackendSync

#### ✅ AIServicesProvider
- **Статус:** Проанализирован, определен как DI контейнер
- **Решение:** Не требует интеграции с BackendSync, работает как инфраструктурный провайдер
