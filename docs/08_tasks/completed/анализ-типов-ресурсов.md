## Обзор типов ресурсов в Timeline Studio

### 1. Media Resources (Медиафайлы)

#### Структура данных
```typescript
interface MediaFile {
  id: string
  name: string
  path: string
  type: 'video' | 'audio' | 'image'
  duration?: number
  size: number
  extension: string
  mime: string
  width?: number
  height?: number
  frameRate?: number
  bitrate?: number
  codec?: string
  hasAudio?: boolean
  hasVideo?: boolean
  createdAt: string
  modifiedAt: string
}
```

#### Специфика
- Физические файлы на диске
- Требуют проверки существования
- Могут быть повреждены или недоступны
- Поддерживают метаданные (длительность, разрешение, кодеки)

### 2. Music Resources (Музыкальные файлы)

#### Структура данных
```typescript
// Использует тот же MediaFile интерфейс
// Отличается только контекстом использования
```

#### Специфика
- Подмножество MediaFile с type='audio'
- Используются как фоновая музыка
- Могут иметь специальные параметры (громкость, fade in/out)

### 3. Effect Resources (Эффекты)

#### Структура данных
```typescript
interface VideoEffect {
  id: string
  name: string
  description: string
  category: string
  thumbnail?: string
  parameters: Record<string, EffectParameter>
  presets: EffectPreset[]
  shader?: string
  isCustom?: boolean
}
```

#### Специфика
- Программные эффекты (не файлы)
- Имеют настраиваемые параметры
- Могут быть встроенными или пользовательскими
- Применяются через CSS фильтры или WebGL шейдеры

### 4. Filter Resources (Фильтры)

#### Структура данных
```typescript
interface VideoFilter {
  id: string
  name: string
  description: string
  category: string
  thumbnail?: string
  parameters: Record<string, FilterParameter>
  presets: FilterPreset[]
  cssFilter?: string
  isCustom?: boolean
}
```

#### Специфика
- Похожи на эффекты, но проще
- Обычно цветокоррекция и стилизация
- Применяются через CSS фильтры

### 5. Transition Resources (Переходы)

#### Структура данных
```typescript
interface Transition {
  id: string
  type: TransitionType
  name?: string
  labels?: { ru: string; en: string }
  duration: number
  parameters?: TransitionParameters
  preview?: string
  category?: string
}
```

#### Специфика
- Анимации между клипами
- Имеют фиксированную длительность
- Параметры влияют на характер перехода
- Могут быть направленными

### 6. Template Resources (Шаблоны раскладки)

#### Структура данных
```typescript
interface MediaTemplate {
  id: string
  type: 'single' | 'split' | 'grid' | 'pip' | 'custom'
  name: string
  slots: TemplateSlot[]
  aspectRatio?: string
  thumbnail?: string
}
```

#### Специфика
- Определяют расположение видео на экране
- Имеют слоты для размещения медиа
- Поддерживают разные соотношения сторон
- Статические (не анимированные)

### 7. Style Template Resources (Стилистические шаблоны)

#### Структура данных
```typescript
interface StyleTemplate {
  id: string
  name: { ru: string; en: string }
  type: 'intro' | 'outro' | 'lower-third' | 'title' | 'transition'
  duration: number
  thumbnail: string
  parameters: StyleParameter[]
  animations: Animation[]
}
```

#### Специфика
- Анимированные шаблоны
- Имеют timeline с ключевыми кадрами
- Настраиваемый текст и цвета
- Экспортируются как готовые секции

### 8. Subtitle Resources (Стили субтитров)

#### Структура данных
```typescript
interface SubtitleStyle {
  id: string
  name: string
  fontFamily: string
  fontSize: number
  fontWeight: string
  color: string
  backgroundColor?: string
  position: SubtitlePosition
  animation?: SubtitleAnimation
}
```

#### Специфика
- Визуальные стили для текста
- Поддерживают анимации появления/исчезновения
- Могут иметь разные позиции на экране

## Общие паттерны и различия

### Общие свойства всех ресурсов
1. **Идентификация**: id, name
2. **Категоризация**: type, category
3. **Визуализация**: thumbnail/preview
4. **Метаданные**: description, labels

### Ключевые различия

| Тип | Источник | Параметризация | Применение | Хранение |
|-----|----------|----------------|------------|-----------|
| Media/Music | Файлы | Нет | Прямое размещение | Ссылка на файл |
| Effects/Filters | Код | Да | Обработка | JSON конфигурация |
| Transitions | Код | Да | Анимация | JSON конфигурация |
| Templates | Код | Частично | Компоновка | JSON структура |
| Style Templates | Код | Да | Генерация контента | JSON + анимации |
| Subtitles | Код | Да | Оверлей | JSON стили |

## Предложение по унификации

### 1. Базовый интерфейс ресурса
```typescript
interface BaseResource {
  id: string
  name: string | LocalizedString
  type: ResourceType
  category?: string
  thumbnail?: string
  metadata?: ResourceMetadata
}

interface ResourceMetadata {
  description?: string | LocalizedString
  tags?: string[]
  author?: string
  version?: string
  createdAt?: string
  modifiedAt?: string
}
```

### 2. Расширенные интерфейсы
```typescript
interface ParametrizableResource extends BaseResource {
  parameters: Record<string, ResourceParameter>
  presets?: ResourcePreset[]
}

interface FileBasedResource extends BaseResource {
  path: string
  size: number
  checksum?: string
}

interface AnimatedResource extends BaseResource {
  duration: number
  timeline?: AnimationTimeline
}
```

### 3. Унифицированный тип ресурса
```typescript
type UnifiedResource = 
  | (MediaResource & FileBasedResource)
  | (EffectResource & ParametrizableResource)
  | (TransitionResource & ParametrizableResource & AnimatedResource)
  | (TemplateResource & Partial<ParametrizableResource>)
  | (StyleTemplateResource & ParametrizableResource & AnimatedResource)
  | (SubtitleResource & ParametrizableResource)
```
