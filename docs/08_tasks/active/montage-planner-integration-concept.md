# Концепция интеграции Montage Planner через AI Chat

**Дата:** 2025-01-18
**Статус:** Планирование (переработка)
**Автор:** Claude Code

## Обзор

Вместо создания сложного UI с выбором параметров, интегрируем планирование монтажа через **AI Chat с контекстными промтами**.

**Workflow:** Анализ AI Director → Умные промты в чате → AI создаёт план → Применение

## Текущее состояние

1. ✅ **Выбор файлов** - выбор видео из медиапула
2. ✅ **Режим анализа** - Fast/Balanced/Quality
3. ✅ **Прогресс анализа** - визуализация процесса

2. 🎯 **Генерация плана** с генетическим алгоритмом

## Новый подход: AI-промты вместо UI

### Проблема старого подхода
❌ Радиокнопки для выбора стиля (Dynamic, Cinematic...)
❌ Слайдеры для параметров
❌ Чекбоксы для настроек
❌ Сложный UI для того, что можно описать словами

### Решение: Контекстные промты в AI Chat

После анализа AI Director в **AI Chat появляются умные подсказки**:

```
┌─────────────────────────────────────────────────────────────┐

### Этап 1: Анализ (уже есть)
AI Director анализирует видео и сохраняет результаты в контекст

### Этап 2: Умные промты (НОВОЕ)
AI Chat показывает **контекстные кнопки-промты** на основе результатов анализа:

**Если обнаружена музыка:**
- 🎵 "Создай music video синхронно с ритмом"
- 🎸 "Нарежь клип под бит музыки"

**Если много динамичных сцен:**
- ⚡ "Сделай энергичный монтаж с быстрыми нарезками"
- 🏃 "Создай спортивный ролик"

**Если обнаружены лица:**
- 👤 "Сделай фокус на людях и эмоциях"
- 💬 "Создай интервью-стиль"

**Если длинные красивые кадры:**
- 🎞️ "Кинематографичный монтаж с плавными переходами"
- 🌅 "Медитативный ролик с природой"

**Универсальные промты:**
- 📱 "Адаптируй для TikTok/Reels (вертикально, 30-60 сек)"
- 📺 "Создай YouTube intro (5-10 секунд)"
- ⏱️ "Сожми до 2 минут, оставь лучшее"

### Этап 3: AI создаёт план
Пользователь нажимает промт или пишет свой → AI:
1. Берёт контекст анализа (сцены, моменты, качество)
2. Генерирует план через backend (генетический алгоритм)
3. Применяет к таймлайну автоматически
4. Показывает что сделал в чате

**Пример диалога:**
```
User: [нажал "Создай динамичный монтаж на 2 минуты"]

AI: ✅ Создаю динамичный монтаж!

Используются:
• 8 лучших моментов (importance > 80%)
• Быстрые переходы (cut)
• Синхрон с музыкальным ритмом
• Целевая длина: 2:03

✨ План создан и применён к таймлайну!

📊 Статистика:
• 8 сегментов
• 12 переходов
• Средняя длина сегмента: 15.4 сек

### Логика работы

```typescript
// Анализатор контекста для генерации промтов
export function analyzeContextForPrompts(
  analysisResult?: ComprehensiveAnalysisResult,
  mediaFiles?: MediaFile[]
) {
  const prompts: SuggestedPrompt[] = []

  // Универсальные промты (всегда показываем)
  prompts.push(
    {
      id: 'quick-tiktok',
      emoji: '📱',
      text: 'Адаптируй для TikTok - вертикально, 60 секунд',
      category: 'platform'
    },
    {
      id: 'highlight-reel',
      emoji: '⚡',
      text: 'Короткий тизер 30 сек из лучших моментов',
      category: 'quick'
    }
  )

  // Если есть результаты анализа
  if (analysisResult) {
    // Есть музыка?
    if (analysisResult.audio_analysis?.has_music) {
      prompts.push({
        id: 'music-sync',
        emoji: '🎵',
        text: 'Создай music video синхронно с ритмом',
        category: 'style'
      })
    }

    // Много сцен = динамика
    if (analysisResult.scene_analysis?.total_scenes > 10) {
      prompts.push({
        id: 'dynamic-montage',
        emoji: '🎬',
        text: 'Создай динамичный монтаж на 2 минуты',
        category: 'style'
      })
    }

    // Есть лица
    if (analysisResult.vision_analysis?.faces_count > 0) {
      prompts.push({
        id: 'focus-people',
        emoji: '👤',
        text: 'Сделай фокус на людях и эмоциях',
        category: 'style'
      })
    }

    // Длинные сцены = кинематографично
    if (analysisResult.scene_analysis?.avg_scene_duration > 10) {
      prompts.push({
        id: 'cinematic',
        emoji: '🎞️',
        text: 'Кинематографичный ролик с плавными переходами',
        category: 'style'
      })
    }
  }

  return prompts
}
```

### AI Suggestions Panel компонент

```typescript
export function AISuggestionsPanel({
  analysisResult,
  onPromptClick
}: Props) {
  const prompts = analyzeContextForPrompts(analysisResult)

  return (
    <div className="p-4 bg-muted/30 border-b">
      {analysisResult && (
        <div className="mb-3 text-sm text-muted-foreground">
          ✨ Анализ завершён! {analysisResult.scene_analysis?.total_scenes} сцен,
          {analysisResult.moment_analysis?.total_moments} моментов
        </div>
      )}

      <div className="mb-2 text-xs font-medium">💡 Что можно сделать:</div>

      <div className="flex flex-wrap gap-2">
        {prompts.map(prompt => (
          <Button
            key={prompt.id}
            variant="outline"
            size="sm"
            onClick={() => onPromptClick(prompt.text)}
            className="text-xs"
          >
            {prompt.emoji} {prompt.text}
          </Button>
        ))}
      </div>
    </div>
  )
}
```

### Backend Integration

AI Chat tool для генерации плана монтажа:

```typescript
// src/features/ai-chat/tools/automation/generate-montage-plan.ts
export const generateMontagePlanTool: IAITool = {
  name: 'generate_montage_plan',
  description: 'Генерирует оптимальный план монтажа на основе AI анализа',

  inputSchema: {
    prompt: 'string', // "динамичный монтаж на 2 минуты"
    useAnalysisContext: 'boolean', // использовать результаты AI Director
  },

  async execute(input) {
    // 1. Получить контекст анализа из AI Director
    const analysisResult = await getLatestAnalysisResult()

    // 2. Парсим промт пользователя
    const intent = parseUserIntent(input.prompt)
    // -> { style: 'dynamic', duration: 120, priorities: [...] }

    // 3. Вызываем backend с генетическим алгоритмом
    const plan = await commands.generateMontagePlan({
      scenes: analysisResult.scene_analysis,
      moments: analysisResult.moment_analysis,
      audio: analysisResult.audio_analysis,
      settings: {
        style: intent.style,
        target_duration: intent.duration,
        prioritize_quality: true,
        sync_with_audio: intent.syncAudio ?? true,
      }
    })

    // 4. Применяем план к таймлайну
    await applyPlanToTimeline(plan)

    // 5. Возвращаем результат для чата
    return {
      success: true,
      message: formatPlanSummary(plan),
      data: plan
    }
  }
}
```

Backend остаётся тот же (генетический алгоритм уже есть)

## Преимущества нового подхода

### Для пользователя
1. ✅ **Естественный интерфейс** - говорим на языке, а не кликаем радиокнопки
2. ✅ **Умные подсказки** - система сама предлагает что подходит
3. ✅ **Гибкость** - можно описать любую идею своими словами
4. ✅ **Быстрее** - один клик вместо настройки 5 параметров
5. ✅ **Понятнее** - "создай тизер 30 сек" vs "style=dynamic, duration=30, cut_type=fast"

### Для разработки
1. ✅ **Минимум UI** - не нужны сложные компоненты настроек
2. ✅ **Переиспользование** - используем готовый AI Chat
3. ✅ **Расширяемо** - легко добавлять новые промты
4. ✅ **Проще поддержка** - меньше кода для поддержки
5. ✅ **Естественная интеграция** - промты = AI инструменты (уже 48+)

## Альтернативные подходы

### ✅ Вариант A: AI Suggestions Panel в чате (ВЫБРАН)

- Можно написать свой промт или кликнуть готовый
- ✅ Естественный интерфейс
- ✅ Минимум кода
- ✅ Гибкий и расширяемый
- ✅ Переиспользует AI Chat инфраструктуру

### Вариант B: Сложный UI с настройками (ОТКЛОНЁН)
- Радиокнопки, слайдеры, чекбоксы
- Отдельный таб в AI Director
- ❌ Много кода для поддержки
- ❌ Менее гибко (заданные параметры)
- ❌ Дублирует возможности AI чата

### Вариант C: Автоматическое планирование без UI
- План генерируется автоматически после анализа
- ❌ Нет контроля пользователя
- ❌ Может быть не то, что нужно
- ❌ Медленно и расходует ресурсы
