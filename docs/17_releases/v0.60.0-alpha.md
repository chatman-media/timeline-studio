# Timeline Studio v0.60.0-alpha Release Notes

*Дата релиза: 3 августа 2025*

## 🎯 Обзор релиза

Первый публичный альфа-релиз Timeline Studio с базовой AI функциональностью на основе локальных моделей Ollama. Этот релиз предназначен для раннего тестирования и получения обратной связи от сообщества.

- **Windows**: [Timeline-Studio-Setup-0.60.0.exe](https://github.com/chatman-media/timeline-studio/releases/tag/v0.60.0-alpha)
- **macOS**: [Timeline-Studio-0.60.0.dmg](https://github.com/chatman-media/timeline-studio/releases/tag/v0.60.0-alpha)
- **Linux**: [timeline-studio_0.60.0_amd64.deb](https://github.com/chatman-media/timeline-studio/releases/tag/v0.60.0-alpha)

## ✨ Новые возможности

### 🤖 AI интеграция с Ollama
- **100% локальная обработка** - все AI операции выполняются на вашем устройстве
- **Поддержка легких моделей** - Llama 3.2, Phi-3, Gemma 2, Qwen 2.5
- **Анализ видео** - детекция сцен и ключевых моментов
- **Генерация субтитров** - базовая транскрипция и синхронизация
- **Без подписки** - используйте бесплатные локальные модели

### 🎬 Базовый видеоредактор
- Timeline с поддержкой множественных треков
- Импорт популярных форматов (MP4, MOV, AVI, MKV)
- Базовые инструменты обрезки и перестановки
- Простые переходы и эффекты
- Экспорт в MP4 (1080p)

### 🌍 Многоязычность
- 15 языков интерфейса
- Автоматическое определение языка системы
- Полная локализация всех компонентов

### 🚀 Производительность
- Миграция на Biome для 10x ускорения линтинга
- Оптимизированная сборка с Tauri v2
- Эффективное использование памяти
- GPU ускорение для рендеринга (где доступно)

## 🔧 Технические изменения

### Инфраструктура
- **Tauri v2.2.0** - последняя версия фреймворка
- **Next.js 15** с React 19 RC
- **Biome** заменил ESLint для линтинга и форматирования
- **FFmpeg 7.0** для обработки медиа

### CI/CD улучшения
- Автоматизированная сборка для всех платформ
- Оптимизация Windows сборки (предсобранные FFmpeg библиотеки)
- GitHub Actions workflow для альфа-релизов
- Кэширование зависимостей для ускорения сборки

### Безопасность
- Изоляция процессов через Tauri sandbox
- CSP политики для защиты от XSS
- Локальное хранение всех данных
- Валидация медиафайлов

## 🐛 Известные проблемы

### Не блокирующие
- **~1860 TypeScript ошибок** - не влияют на работу, будут исправлены в Beta
- **Первый запрос к Ollama медленный** - загрузка модели в память
- **Нет GPU ускорения для Ollama** - только CPU режим в альфе

### Требуют внимания
- Высокое использование памяти при работе с большими проектами
- Ограниченная поддержка кодеков на некоторых платформах
- Возможные проблемы со стабильностью при длительной работе

## 📋 Системные требования

### Минимальные
- **ОС**: Windows 10/11, macOS 12+, Ubuntu 22.04+
- **RAM**: 8GB
- **CPU**: 4 ядра, 2.5GHz
- **Место на диске**: 10GB
- **Ollama**: v0.1.45+ (для AI функций)

### Рекомендуемые
- **RAM**: 16GB
- **CPU**: 8 ядер, 3.0GHz
- **GPU**: Любая с 4GB VRAM
- **Место на диске**: 20GB
- **Модели Ollama**: 2-4GB свободного места

## 🚀 Быстрый старт

### 1. Установка Ollama
```bash
# macOS
brew install ollama

# Linux
curl -fsSL https://ollama.ai/install.sh | sh

# Windows - скачать с https://ollama.ai/download/windows
```

### 2. Загрузка модели
```bash
# Рекомендуемая модель для начала (1.6GB)
ollama pull gemma2:2b

# Запуск сервера
ollama serve
```

### 3. Запуск Timeline Studio
1. Установите приложение из релиза
2. Запустите Timeline Studio
3. Выберите язык интерфейса
4. Создайте новый проект
5. Начните работу!
