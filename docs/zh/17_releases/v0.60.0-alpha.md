# Timeline Studio v0.60.0-alpha Release Notes

*Release Date: August 3, 2025*

## 🎯 Release Overview

First public alpha release of Timeline Studio with basic AI functionality based on local Ollama models. This release is intended for early testing and community feedback.

## 📦 Download

- **Windows**: [Timeline-Studio-Setup-0.60.0.exe](https://github.com/chatman-media/timeline-studio/releases/tag/v0.60.0-alpha)
- **macOS**: [Timeline-Studio-0.60.0.dmg](https://github.com/chatman-media/timeline-studio/releases/tag/v0.60.0-alpha)
- **Linux**: [timeline-studio_0.60.0_amd64.deb](https://github.com/chatman-media/timeline-studio/releases/tag/v0.60.0-alpha)

## ✨ New Features

### 🤖 AI Integration with Ollama
- **100% local processing** - all AI operations run on your device
- **Lightweight model support** - Llama 3.2, Phi-3, Gemma 2, Qwen 2.5
- **Video analysis** - scene and key moment detection
- **Subtitle generation** - basic transcription and synchronization
- **No subscription** - use free local models

### 🎬 Basic Video Editor
- Timeline with multiple track support
- Import popular formats (MP4, MOV, AVI, MKV)
- Basic trimming and rearranging tools
- Simple transitions and effects
- Export to MP4 (1080p)

### 🌍 Multilingual Support
- 10 interface languages (EN, RU, ES, FR, DE, PT, ZH, JA, KO, TR)
- Automatic system language detection
- Complete localization of all components

### 🚀 Performance
- Migration to Biome for 10x faster linting
- Optimized build with Tauri v2
- Efficient memory usage
- GPU acceleration for rendering (where available)

## 🔧 Technical Changes

### Infrastructure
- **Tauri v2.2.0** - latest framework version
- **Next.js 15** with React 19 RC
- **Biome** replaced ESLint for linting and formatting
- **FFmpeg 7.0** for media processing

### CI/CD Improvements
- Automated builds for all platforms
- Windows build optimization (pre-built FFmpeg libraries)
- GitHub Actions workflow for alpha releases
- Dependency caching for faster builds

### Security
- Process isolation via Tauri sandbox
- CSP policies for XSS protection
- Local storage of all data
- Media file validation

## 🐛 Known Issues

### Non-Blocking
- **~1860 TypeScript errors** - don't affect functionality, will be fixed in Beta
- **First Ollama request slow** - model loading into memory
- **No GPU acceleration for Ollama** - CPU only mode in alpha

### Needs Attention
- High memory usage with large projects
- Limited codec support on some platforms
- Possible stability issues during extended use

## 📋 System Requirements

### Minimum
- **OS**: Windows 10/11, macOS 12+, Ubuntu 22.04+
- **RAM**: 8GB
- **CPU**: 4 cores, 2.5GHz
- **Disk Space**: 10GB
- **Ollama**: v0.1.45+ (for AI features)

### Recommended
- **RAM**: 16GB
- **CPU**: 8 cores, 3.0GHz
- **GPU**: Any with 4GB VRAM
- **Disk Space**: 20GB
- **Ollama Models**: 2-4GB free space

## 🚀 Quick Start

### 1. Install Ollama
```bash
# macOS
brew install ollama

# Linux
curl -fsSL https://ollama.ai/install.sh | sh

# Windows - download from https://ollama.ai/download/windows
```

### 2. Download Model
```bash
# Recommended model to start (1.6GB)
ollama pull gemma2:2b

# Start server
ollama serve
```

### 3. Launch Timeline Studio
1. Install the application from release
2. Launch Timeline Studio
3. Select interface language
4. Create new project
5. Start working!
