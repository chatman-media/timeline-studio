# Timeline Studio 定价模型

## 🎯 定价理念

Timeline Studio 遵循 **"本地免费，云端付费"** 原则：
- 能在用户计算机上运行的所有功能 - **免费**
- 云服务和第三方API - **付费**
- 对用户最大程度的透明和诚实
