# AI Domain Expansion - Краткое резюме

## 🔍 Что обнаружено

После анализа `src/features/ai-chat/tools` и других AI-связанных папок выявлен **огромный объем функционала**, который требует систематизации:

### 📊 Статистика
- **AI Chat Tools**: 48 инструментов в 4 доменах
- **AI Content Intelligence**: 25+ компонентов/сервисов/хуков  
- **Montage Planner**: 15+ AI-интеграционных сервисов
- **Person Identification**: 8+ сервисов и компонентов
- **Recognition**: 6+ сервисов YOLO/scene detection
- **Transcription**: 5+ компонентов и хуков

**Итого**: ~200+ AI-связанных компонентов требуют миграции!

## 🏗️ Предлагаемое решение

### Расширение доменной архитектуры на 4 новых домена:

#### 1. `domains/ai-tools` - AI Инструменты для чата
- **Core**: 18 инструментов (timeline, resources, browser, player)
- **Analysis**: 15 инструментов (video/audio analysis, content intelligence)  
- **Automation**: 10 инструментов (batch processing, workflows)
- **Integration**: 5 инструментов (export, platform integration)

#### 2. `domains/content-intelligence` - Интеллектуальный анализ
- Engines для анализа сцен и генерации скриптов
- Orchestrators для управления пайплайнами
- Factories для создания сервисов
- React провайдеры и XState машины

#### 3. `domains/montage-planning` - Планирование монтажа
- Сервисы анализа контента и генерации планов
- AI интеграция для качественного анализа
- Машины состояний для workflow
- Интеграция с таймлайном

#### 4. `domains/media-recognition` - Распознавание в медиа
- Person identification (детекция и трекинг лиц)
- Object recognition (YOLO, scene context)
- Transcription (Whisper, субтитры)
- Единые интерфейсы для всех типов распознавания

## 🎯 Ключевые проблемы, которые решаем

### Критические дублирования
- **PersonDatabaseService**: идентичные реализации в 2 местах
- **SceneAnalysisEngine**: дублирование между features и domains
- **WhisperService**: пересечения в 3 модулях
- **UnifiedContentAnalysis**: 8+ определений интерфейса

### Архитектурные проблемы
- Циклические зависимости между features
- Смешение UI и бизнес-логики
- Отсутствие единой точки входа для AI
- Дублированная конфигурация в каждом модуле
