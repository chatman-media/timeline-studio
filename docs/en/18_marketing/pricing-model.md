# Timeline Studio Pricing Model

## 🎯 Pricing Philosophy

Timeline Studio follows the principle **"Local for free, cloud for a fee"**:
- Everything that can run on the user's computer - **FREE**
- Cloud services and third-party APIs - **PAID**
- Maximum transparency and honesty with users
