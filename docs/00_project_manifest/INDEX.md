## 🔄 Как обновляется статистика

### Автоматический пересчет

Статистика пересчитывается скриптом:

```bash
bun run scripts/count-features-stats.ts
```

Скрипт анализирует:
- ✅ Все фичи в `/src/features/` (кроме исключенных)
- ✅ Компоненты, хуки, сервисы, типы, тесты
- ✅ Готовность из README.md каждой фичи

Подробности: [scripts/README-stats.md](../../scripts/README-stats.md)
