## 2. НАЗНАЧЕНИЕ ФИЧИ

### Основное предназначение:
Управление пользовательскими настройками приложения Timeline Studio с поддержкой многоязычности, API ключей, профилей производительности и интеграции с социальными сетями.

### Ключевые области отвественности:

#### 2.1 Управление интерфейсом
- Переключение активной вкладки браузера (media, music, transitions, effects, filters, templates)
- Смена макетов интерфейса (default, options, vertical, dual)
- Управление видимостью браузера, временной шкалы и опций

#### 2.2 Управление медиа и путями
- Настройка пути для сохранения скриншотов
- Настройка пути для скриншотов плеера
- Регулировка громкости плеера (0-100)

#### 2.3 Интеграция с AI сервисами
- Управление API ключами для OpenAI, Claude, Groq, DeepSeek
- Поддержка OAuth подключений для социальных сетей
- Валидация API ключей через Tauri backend

#### 2.4 Оптимизация производительности
- Включение/отключение GPU ускорения
- Выбор GPU кодера (auto, h264, h265, vp9, av1)
- Настройка количества одновременных заданий
- Качество рендера и фоновый рендеринг
- Оптимизация Timeline (виртуализация, overscan)

#### 2.5 Сетевые настройки
- Настройка прокси сервера (тип, хост, порт, аутентификация)
- Импорт/экспорт настроек из .env файлов

#### 2.6 Автосохранение
- Включение/отключение автосохранения проектов
- Настройка интервала автосохранения

## 3. ПОЛНОТА РЕАЛИЗАЦИИ

### Компоненты: ✅ ПОЛНОСТЬЮ РЕАЛИЗОВАНЫ

#### Модальное окно и контейнер вкладок:
1. **UserSettingsModal** - Главное модальное окно
   - Интеграция с modal provider
   - Кнопки Cancel/Save
   - Поддержка i18n

2. **UserSettingsModalTabs** - Контейнер с вкладками
   - Состояние активной вкладки
   - Динамический показ вкладки "Разработка" (только в dev)
   - Организация 5 основных вкладок

#### Компоненты вкладок:
1. **GeneralSettingsTab** - Основные настройки
   - Выбор языка интерфейса (15 языков)
   - Пути скриншотов (с диалогом выбора папки)
   - Настройки автосохранения

2. **PerformanceSettingsTab** - Производительность
   - GPU ускорение
   - Выбор GPU кодера
   - Количество одновременных заданий
   - Качество рендера
   - Фоновый рендеринг и задержка
   - Оптимизация Timeline (виртуализация)

3. **AiServicesTab** - AI сервисы
   - Input поля для API ключей (с маскировкой)
   - Автосохранение при вводе
   - Поддержка OpenAI, Claude, Groq, DeepSeek
   - Безопасное отображение (••••)

4. **SocialNetworksTab** - Социальные сети
   - OAuth подключения
   - YouTube, TikTok, Vimeo, Telegram

5. **DevelopmentTab** - Разработка (dev-only)
   - Codecov интеграция
   - Analytics настройки
   - Показывается только в development режиме

#### Компоненты-виджеты:
1. **ApiKeyInput** - Input поле для API ключей с маскировкой
2. **KeyStatusIndicator** - Индикатор статуса ключа (valid, invalid, testing, not_set)
3. **OAuthConnection** - Компонент для OAuth подключений

### Хуки: ✅ ПОЛНОСТЬЮ РЕАЛИЗОВАНЫ

1. **useUserSettings()** - Главный хук
   - Адаптер, проксирующий доменную реализацию
   - 50+ методов и свойств
   - Полная совместимость с legacy API
   - Поддержка всех областей настроек

2. **useApiKeys()** - Работа с API ключами
   - Операции: сохранение, тестирование, удаление
   - OAuth: генерация URL, обмен кодом, обновление токена
   - Импорт/экспорт из .env
   - Валидация с обработкой ошибок
   - Состояние загрузки для каждого сервиса

3. **useAutoRevalidation()** - Автоматическая переval идация
   - Периодическая проверка валидности ключей (24 часа)
   - Минимальный интервал между проверками (1 час)
   - Callbacks для успеха/ошибки
   - Настраиваемый список сервисов

### Сервисы: ✅ ПОЛНОСТЬЮ РЕАЛИЗОВАНЫ

1. **UserSettingsProvider** - React Context провайдер
   - Интеграция с ProjectManagementOrchestrator
   - Подписка на изменения настроек
   - Предоставляет доменные данные
   - Поддерживает 15 категорий настроек
   - Методы обновления для каждой категории

### Типизация: ✅ ПОЛНАЯ

- **UserSettingsContextValue** - 50+ свойств и методов
- **ApiKeyInfo** - информация о ключе
- **ValidationResult** - результат валидации
- **OAuthCredentials** - OAuth параметры
- TypeScript strict mode

1. `TypeError: mock(module, fn) requires a function` - некорректная синтаксис vi.mock()

3. `ReferenceError: describe is not defined` - проблемы с инициализацией test environment

**Тесты не запускаются**, требуется исправление конфигурации Vitest.

#### 1. Неправильное использование renderHook в тестах
```typescript

// ❌ renderHook требует DOM окружение, которое не инициализировано
```

#### 2. Некорректная синтаксис vi.mock()
```typescript
// В нескольких компонентах тестов:
vi.mock("../../hooks/use-user-settings")
// ❌ Требуется функция второго аргумента
// ✅ Должно быть:
vi.mock("../../hooks/use-user-settings", () => ({ useUserSettings: ... }))
```

#### 3. Отсутствие валидации в AiServicesTab
```typescript
// ai-services-tab.tsx
// ❌ Проверка "!value.includes('••••')" ненадежна
```
