## Рекомендации по Use Cases

### Для личных проектов и обучения
**→ Ollama (moondream2)**
- Бесплатно
- Легко начать
- Достаточно для большинства задач

### Для малого бизнеса / стартапов
**→ DeepSeek Vision**
- Очень низкая стоимость (~$1 за 100 видео)
- Хорошее качество
- Масштабируется

### Для профессионального use
**→ GPT-4o**
- Надёжность и стабильность API
- Высокое качество
- Доступная цена ($8 за 100 видео)

### Для критичных проектов
**→ Claude 4.5 Sonnet**
- Лучшее понимание контекста
- Продвинутый reasoning
- Премиум качество

## Подробное сравнение

### Ollama ⭐ Рекомендуется для начала

**Когда использовать:**
- Разработка и тестирование
- Ограниченный бюджет
- Важна конфиденциальность
- Есть GPU (8GB+ VRAM для llava)

**Когда НЕ использовать:**
- Нужно максимальное качество
- Нет GPU (будет медленно)
- Критична скорость (облако быстрее)

**Лучшая модель**: `llava` (если есть GPU) или `moondream2` (компактная)

### DeepSeek Vision 💰 Лучший баланс

**Когда использовать:**
- Production с большим количеством видео
- Нужен баланс цена/качество
- Бюджет ограничен но есть

**Когда НЕ использовать:**
- Нужно абсолютно бесплатно
- Критична максимальная точность

**Цена**: $0.14 за 1M input tokens + $0.28 за 1M output tokens
**Практика**: ~$0.01 за 10-минутное видео (10 кадров)

### OpenAI GPT-4o 🎯 Высокое качество

**Когда использовать:**
- Production проекты
- Важна точность и детальность
- Нужна стабильность API

**Когда НЕ использовать:**
- Очень большие объёмы (дорого)
- Достаточно более простых моделей

**Цена**: $2.50 за 1M input tokens + $10.00 за 1M output tokens
**Практика**: ~$0.08 за 10-минутное видео (5 кадров)

### Claude 4.5 Sonnet 👑 Премиум

**Когда использовать:**
- Нужно лучшее качество
- Сложные задачи анализа
- Критична точность

**Когда НЕ использовать:**
- Ограниченный бюджет
- Большие объёмы видео

**Цена**: $3.00 за 1M input tokens + $15.00 за 1M output tokens
**Практика**: ~$0.12 за 10-минутное видео (5 кадров)

## Настройка в приложении

### 1. Ollama (локальный)

```bash
# Установить Ollama
brew install ollama  # macOS

# Запустить сервис
ollama serve

# Скачать модель
ollama pull moondream2
```

В приложении:
- Settings → AI Analysis → Provider: **Ollama**
- Model: **moondream2** (или llava)
- API Key: не требуется

### 2. DeepSeek

1. Зарегистрироваться: https://platform.deepseek.com
2. API Keys → Create new key
3. Пополнить баланс: минимум $5

В приложении:
- Settings → API Keys → DeepSeek API Key: `sk-...`
- Settings → AI Analysis → Provider: **DeepSeek**
- Model: **deepseek-vl**

### 3. OpenAI

1. Зарегистрироваться: https://platform.openai.com
2. API Keys → Create new secret key
3. Добавить payment method

В приложении:
- Settings → API Keys → OpenAI API Key: `sk-proj-...`
- Settings → AI Analysis → Provider: **OpenAI**
- Model: **gpt-4o**

### 4. Claude

1. Зарегистрироваться: https://console.anthropic.com
2. API Keys → Create key
3. Пополнить credits

В приложении:
- Settings → API Keys → Claude API Key: `sk-ant-...`
- Settings → AI Analysis → Provider: **Claude**
- Model: **claude-4-5-sonnet**


```typescript

```

```typescript
// Разработка: Ollama (бесплатно)
```

## Часто задаваемые вопросы

**Q: Можно ли использовать несколько провайдеров?**
A: Да, можно переключаться в Settings → AI Analysis

**Q: Какой провайдер самый быстрый?**
A: Ollama (локально) при наличии GPU, иначе GPT-4o

**Q: Можно ли использовать бесплатно для коммерческих проектов?**
A: Да, Ollama полностью бесплатен и подходит для commercial use

**Q: Что делать если закончились credits?**
A: Пополнить баланс на платформе провайдера или переключиться на Ollama

**Q: Можно ли использовать свой сервер Ollama?**
A: Да, указать custom endpoint в настройках (будет добавлено)
