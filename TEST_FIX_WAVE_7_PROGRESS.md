## Key Learnings

### 1. Automatic Refactoring Pitfalls

When using automated scripts to add wrapper parameters:
- ❌ **Don't** insert parameters in the middle: `renderHook((, { wrapper }) =>`
- ✅ **Do** append as second argument: `renderHook(() => ..., { wrapper })`

### 2. Mock Import Order

Mocking `@/config/providers` prevents import chain issues:
```typescript
// Mock app-providers BEFORE any imports that might use it
vi.mock("@/config/providers/app-providers", ...)
vi.mock("@/config/providers", ...)

// THEN import hooks
import { useTimelineProject } from "@/domains/video-editing"
```
